# 塔架中段定制化设计流程

> **文档状态（2026-09-30 校核对齐）**：本文档为 **v1 旧版**，原描述「按历史设计**从后往前逐级匹配、未命中逐级回退**」的范式。该范式**已废弃**，**已由《塔架中段-正向设计流程》（`design/塔架中段-正向设计流程.md`）整体取代**。本文件仅作历史留档；正文数据已按当前实现真值（本体 `TowerMidSection.owl` v16.5）同步校对，如与正向流程文档冲突，以正向流程文档为准。

## 一、输入条件

| 输入项 | 说明 |
|--------|------|
| 塔架主体信息表 | 塔筒段数，标高(下)(m)，dbottom（mm）外径，标高(上)(m)，dtop（mm）外径，壁厚(mm)等几何参数（`TowerGeoInput_*.xlsx`，含 Description / TowerGeo / Flange / Door / V-Flange sheet） |
| 项目布局表 | 中间段 sheet 直读：平台位置、爬梯支撑长/宽、踏棍宽度、机型、扶持高度等（`项目布局表.xlsx`） |
| 机型 | 风力发电机组型号（V12 / V15 / V17 / V19） |
| 升降机配置 | **固定为「钢绳导向升降机」**（⇒ 必有扶持） |
| 区域 | **固定为「中国」**（⇒ 电缆线夹隔开，`T_or_F=1`） |
| 附件连接方式 | **固定为「焊接」**（固定常量） |

## 二、设计流程

> **当前范式：完全正向、单链路、无匹配、无回退。** 全部环节必做，由「主体信息表 + 布局表」两张输入表 + 设计规则一次性算出全部参数；不依赖历史设计实例库，也不存在命中 / 回退分支。

按数据依赖排序的单一顺序链路（BPMN `ontology/bpmn/TowerMidDesign.bpmn`：9 个 `serviceTask` S0..S8 + 10 条顺序连线，**无排他网关、无回退**）：

```
S0 输入解析 ─► S1 塔筒外形/分段几何 ─► S2 升降机/扶持(9) ─► S3 配件类型(8)
   ─► S4 直径(7) ─► S5 高度(6) ─► S6 筒节(5) ─► S7 平台(4) ─► S8 输出参数表
```

### 步骤 1：塔筒外形设计（S0 输入解析 + S1 分段几何）

- 段数 `section_qty = 法兰个数 − 1`（**不读** `TowerGeo` 段数列）。
- 逐筒节读取 高 / 下外径 / 上外径 / 壁厚；段总长 `SEC_H_total = Σ筒节高`。
- 累计环焊缝位置；任意高度处内径 `diCal(h,n)`（锥段线性插值后减 2×对应壁厚）。
- 中径 `D_mid = D_out − T`（= `D_in + T`）。

### 步骤 2：升降机设计（S2，旧步骤 9）

- 升降机固定 = 钢绳导向 ⇒ **必有扶持**。
- 扶持高度 `H_SUPPORT` **直读布局表 (12,n)**（老应用 `midSkelW` 口径；`support()` 为死代码，不采用）。
- 校验扶持到环焊缝距离 `> 100`（本体 `supportToWeldDistance`）。

### 步骤 3：配件类型替换（S3，旧步骤 8）

- 附件连接方式固定 = 焊接 ⇒ 取焊接型附件类型总成（`ACCESSORY_TYPE` / `ACCESSORY_CONNECTION_TYPE`）。

### 步骤 4：直径设计（S4，旧步骤 7）

- 电缆托架参数按机型映射（本体 `:机型` 个体 V12 / V15 / V17 / V19）：

| Model | L_CABLE | L1_CABLE_I | L2_CABLE_I |
|---|---|---|---|
| V12 | 420 | 800 | 800 |
| V15 | 420 | 800 | 800 |
| V17 | 800 | 650 | 650 |
| V19 | 560 | 650 | 650 |

- `di_cable_top = diCal(SEC_H_total − 1000, n)`（本体 `lastBracketToTopFlange`，即老应用 `Cable_top_h` = 1000）；`di_cable_down = diCal(980, n)`。
- B/C 视图：`DA_B = diCal(SEC_H − 825)`、`DA_C = diCal(H_SUPPORT + 400)`。

### 步骤 5：高度设计（S5，旧步骤 6）

- 爬梯 / 线槽与塔筒等高：`L_LADDER = L_C = SEC_H_total`（段高恒为 280 整数倍 ⇒ `N_LADDER = L_LADDER/280` 天然为整数，**无需取整**）。
- 第一个踏棍离下法兰（第一法兰）**140mm**（本体 `firstRungToBottomFlange`）。
- 爬梯支撑长度/宽度 `L_LADDER_I` / `W_LADDER_I` 取布局表 (3,n) / (4,n)。

### 步骤 6：筒节设计（S6，旧步骤 5，正向排布）

- **爬梯支撑 / 电缆托架（平齐）排布**：起点 `H1_L = 980`（本体 `firstAccessoryToBottom`）；相邻中心间距候选 `[7,6,5]×280 = [1960,1680,1400]`，**贪心取大**（每步优先 1960），仅当与焊缝干涉时降档，落位区间 `[1400,1960]`（本体 `accessoryCenterSpacing`）。
- **避焊缝判据**：附件**上/下边缘**到焊缝距离 `> 100`（本体 `accessoryToWeldDistance`），边缘偏移 `edgeOffset = W_Rung/2 = 85/2 = 42.5`（`W_Rung` 直读布局表第 14 行）；判据 `|h − w| − edgeOffset > 100`。
- **终止**：最后一个爬梯支撑到平台 ∈ `[840,1960]`（本体 `secondLastToPlatform`，v16.2 下界放宽至 840）。输出 `H{i}_L`（**增量**语义）、`H{i}_L_Exist`（H1..H20，缺失补 `no`）。
- **电缆线夹**（区域 = 中国 ⇒ 隔开）：首组 = `H1_L`，其后每 2 个爬梯支撑增量合并为 1 组线夹；输出 `H{i}_CABLE`（增量）、`H{i}_CABLE_Exist`。最后一个电缆托架在平台上方、距平台 `200`（本体 `lastBracketToPlatform`）。
- **照明**：首灯首选 `2600`（本体 `firstLightHeight ∈ [2600,3000]`）；灯间距首选 `10000`（本体 `lightToLightMaxSpacing ≤ 10000`、`lightToLightMinSpacing ≥ 5000`），仅避焊缝时调小（≥ 5000）；灯型固定「焊接灯」，按螺柱避焊缝 `> 100`（本体 `lightStudToWeldDistance`；`lightStudSpacing = 500`）。
- **爬梯安全锚点** `H_AP` 取布局表 (9,n)。
- **防雷接地螺柱**：每段顶/底法兰**各一组、每组 3 个**（本体 `Flange ⊑ =3 hasLightningGroundingStud`），焊于法兰内径；距爬梯中心线顺时针 `70°`、其余按 `120°` 均布（本体 `lightningStudInstallAngle` 值集 70 / 190 / 310）；顶法兰组距上法兰上表面 `50mm`、底法兰组距下法兰下表面 `50mm`（本体 `lightningStudFlangeDistance = 50`）。输出 `B_B_A`（下端角度）、`B_T_A`（上端角度）**直读布局表 (11,n)/(12,n)**，**非本体规则计算**。

### 步骤 7：平台设计（S7，旧步骤 4）

- 平台位置 `H_platform` 取布局表 (2,n)；本体约束 `platformToTopDistance = 1250`（平台到筒顶）。
- 平台处内径 `DI_platform = diCal(段长 − H_platform, n)`。
- **平台仅输出几何参数，不作物料选型**。

### 步骤 8：输出参数表（S8）

- 每段输出 **3 份 Creo 关系式 txt（GBK）**；TMSD 按老工具目录结构输出**两套**：`<用例>/项目法兰尺寸_骨架关系式/第K段/…` 与 `<用例>/极限法兰尺寸_骨架关系式/第K段/…`。
- 另附方案对比报告（UTF-8），逐段给出本体 19 条数值约束判定结果。

## 三、流程图

```
输入：塔架主体信息表 + 项目布局表（固定项：钢绳导向 / 中国 / 焊接）
                │
                ▼
        S0 输入解析（校验后建立设计会话）
                │
                ▼
        S1 塔筒外形与分段几何（逐筒节 / 段总长 / 焊缝 / diCal）
                │
                ▼
        S2 升降机设计（扶持，旧步骤 9）
                │
                ▼
        S3 配件类型替换（附件连接方式 = 焊接，旧步骤 8）
                │
                ▼
        S4 直径设计（机型→电缆托架，旧步骤 7）
                │
                ▼
        S5 高度设计（梯/线槽 = 段高、梯档 280 / 踏棍 140，旧步骤 6）
                │
                ▼
        S6 筒节设计（附件 / 线夹 / 灯 / 防雷排布，旧步骤 5）
                │
                ▼
        S7 平台设计（旧步骤 4）
                │
                ▼
        S8 输出参数表（3 份 txt × 2 套目录 + 方案对比报告）
                │
                ▼
              结束
```

> **无排他网关、无回退**：BPMN 为 9 个 `serviceTask` 的单一顺序链路（10 条顺序连线）。原「平台内径 ← 筒节 ← 高度 ← 直径 ← 连接方式 ← 机型」匹配链及其命中 / 回退分支（v1）已整体删除。
