# 塔架中段定制化设计流程

## 一、输入条件

| 输入项 | 说明 |
|--------|------|
| 塔架尺寸 | 塔筒段数，标高(下)(m)，dbottom（mm）外径，标高(上)(m)，dtop（mm）外径，壁厚(mm)等几何参数 |
| 机型 | 风力发电机组型号 |
| 升降机配置 | 钢绳导向 / 爬梯导向 |
| 区域 | 全球区域/国家 |

---

## 二、设计流程

### 步骤 1：塔筒外形设计

根据输入的塔架尺寸，完成塔筒外形设计（中段直径和高度）。

### 步骤 2：历史机型匹配（从后往前匹配）

按以下路径**从后往前逐级匹配**历史设计方案：

```
平台所在处内径 ← 筒节 ← 高度 ← 直径 ← 附件连接方式 ← 机型及升降机类型
```

> **核心规则**：
> 1. 从最后一节（内径）往前匹配，越往后命中修改越少，越往前命中修改越多。
> 2. 命中某一级 → 该级及之后的所有设计环节全部复用，不再执行。
> 3. 未命中某一级 → 从该级开始，往后（平台方向）依次完成所有设计环节。
> 4. 每完成一级设计，都要继续走到最后的平台设计。

### 步骤 3：匹配结果与设计执行

#### 3.1 平台所在处内径命中

→ 直接复用原设计图，无需修改。**流程结束。**

#### 3.2 平台所在处内径未命中，筒节命中

→ 进入**平台设计流程**（步骤 4）。**流程结束。**

#### 3.3 平台所在处内径未命中，筒节未命中

→ 先按**筒节约束条件**（步骤 5）修改原设计图 → 再进入**平台设计流程**（步骤 4）。**流程结束。**

#### 3.4 高度未命中

→ 先完成**高度相关修改**（步骤 6）→ 再完成**筒节设计**（步骤 5）→ 再进入**平台设计流程**（步骤 4）。**流程结束。**

#### 3.5 直径未命中

→ 先完成**直径相关修改**（步骤 7）→ 再完成**高度设计**（步骤 6）→ 再完成**筒节设计**（步骤 5）→ 再进入**平台设计流程**（步骤 4）。**流程结束。**

#### 3.6 附件连接方式未命中

→ 先完成**配件类型替换**（步骤 8）→ 再完成**直径设计**（步骤 7）→ 再完成**高度设计**（步骤 6）→ 再完成**筒节设计**（步骤 5）→ 再进入**平台设计流程**（步骤 4）。**流程结束。**

#### 3.7 机型及升降机类型未命中

→ 先完成**升降机设计**（步骤 9）→ 再完成**配件类型替换**（步骤 8）→ 再完成**直径设计**（步骤 7）→ 再完成**高度设计**（步骤 6）→ 再完成**筒节设计**（步骤 5）→ 再进入**平台设计流程**（步骤 4）。**流程结束。**

---

### 步骤 4：平台设计流程

#### 约束条件

- 平台到筒顶距离：**1250mm**

### 步骤 5：筒节设计（约束条件）

从塔架尺寸中提取数据进行设计。

#### 5.1 附件与环焊缝间距

- 附件（爬梯支撑 + 电缆托架，两者平齐）与环焊缝之间：**上下距离 > 100mm**（上下边缘）

#### 5.2 中间附件之间的间距

- 相邻附件中心间距：**≤ 280mm × 7，≥ 280mm × 6**

#### 5.3 首/末附件定位

| 位置 | 尺寸 |
|------|------|
| 第一个附件到底部 | 980mm |
| 倒数第二个配件到平台 | 5 × 280mm ~ 7 × 280mm |
| 最后一个电缆托架（无爬梯支撑）在平台上方 | 距平台 200mm |

#### 5.4 照明设计

| 项目 | 要求 |
|------|------|
| 第一个灯安装高度 | 上方空间 2.6m ~ 3m |
| 灯的类型 | 由机型 + 区域确定 |

#### 5.5 灯的安装间距

| 项目 | 要求 |
|------|------|
| 每个灯的上螺柱间距 | 最大 10m，最小 5m |
| 螺柱间距 | 500mm |

#### 5.6 灯的焊接要求

- 焊接在筒壁上的灯：每个螺柱与焊缝之间距离 **上下 > 100mm**
- 线槽灯：不考虑此约束

### 步骤 6：高度设计

从塔架尺寸中提取数据进行设计。

#### 6.1 梯子更换

- 更换与筒高一致的梯子（高度匹配）

#### 6.2 线槽更换

- 更换与筒高一致的线槽

### 步骤 7：直径设计

从塔架尺寸中提取数据进行设计。

#### 7.1 电缆托架定位

- 电缆托架中心距同侧爬梯支撑的弦长：满足映射关系

### 步骤 8：附件连接方式设计

从塔架尺寸中提取数据进行设计。

#### 8.1 配件类型替换

- 替换适配的配件类型

### 步骤 9：升降机设计

#### 9.1 钢绳导向

| 项目 | 要求 |
|------|------|
| 扶持位置计算公式 | (中段筒高 − 1250mm) ÷ 2 |
| 上下沿与焊缝距离 | > 100mm |
| 水平位置 | 按公式计算 |

#### 9.2 爬梯导向

- 后续补充流程

## 四、设计执行汇总表

| 命中层级 | 内径 | 筒节 | 高度 | 直径 | 连接方式 | 机型 | 需执行的设计环节（按顺序） |
|---------|------|------|------|------|---------|------|--------------------------|
| 内径命中 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | 无（直接复用） |
| 筒节命中 | ✗ | ✓ | ✓ | ✓ | ✓ | ✓ | 平台设计(4) |
| 高度命中 | ✗ | ✗ | ✓ | ✓ | ✓ | ✓ | 筒节设计(5) → 平台设计(4) |
| 直径命中 | ✗ | ✗ | ✗ | ✓ | ✓ | ✓ | 高度设计(6) → 筒节设计(5) → 平台设计(4) |
| 连接方式命中 | ✗ | ✗ | ✗ | ✗ | ✓ | ✓ | 直径设计(7) → 高度设计(6) → 筒节设计(5) → 平台设计(4) |
| 机型命中 | ✗ | ✗ | ✗ | ✗ | ✗ | ✓ | 升降机设计(9) → 配件替换(8) → 直径设计(7) → 高度设计(6) → 筒节设计(5) → 平台设计(4) |
| 全未命中 | ✗ | ✗ | ✗ | ✗ | ✗ | ✗ | 升降机设计(9) → 配件替换(8) → 直径设计(7) → 高度设计(6) → 筒节设计(5) → 平台设计(4) |
