## 4. 信息密度门禁

- 本页为**内容页 · 卡片组 + 架构图**混合：字数约 **520**（≥ 300），图示 **1 组**（分层架构 + 数据流）。
- 容器填充率：左卡内部累计高 ≥ 298 / 304；右卡累计高 ≈ 278 / 304；底部条 ≈ 130 / 142 → 均 ≥ 85%。
- 留白 ≤ 25%（内容页默认 ≤ 35%）；B 区主视觉（架构块）占比 ≥ 30%。
- 兄弟卡尾部对齐：左右两卡等高 336px，内部标题块/正文块 y 轴对齐。
