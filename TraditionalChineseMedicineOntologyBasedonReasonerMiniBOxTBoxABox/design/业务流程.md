## 一、业务定位

本系统把《伤寒论》《金匮要略》的**「病脉证并治」**诊疗逻辑编译成可计算模型，
面向临床辅助场景：**输入一段自然语言的四诊描述，输出六经、方证、方剂与药物，
并给出可追溯的条文依据**。

它不替代医师，而是把「观其脉证，知犯何逆，随证治之」的推理过程**显式化、可复核化**：

- 每一步结论都能回溯到**具体症状/脉象/舌象/腹证**（四诊发现）；
- 每一步结论都能回溯到**具体条文**（《伤寒论》第 X 条）；
- 结论不确定时**不硬凑**，而是给出「还缺什么」与「可能是哪些方证」。

## 二、辨证纲领

> **先辨六经，继辨八纲，再辨方证，乃至药证。**（胡希恕）

这句话是本系统全部业务逻辑的总纲，也是**单向推理链**的业务表达：

```
四诊发现  ──►  判据（合取证据）  ──►  八纲  ──►  六经  ──►  方证  ──►  方剂/药物
（症状/脉/舌/腹）   （Panju）        （表里寒热虚实阴阳）（病位⊓病性）（方证相应）（随证加减）
```

| 环节 | 临床含义 | 系统产出 |
|---|---|---|
| **四诊发现** | 患者能直接报告的客观所见 | 症状 / 脉象 / 舌象 / 腹证 个体 |
| **判据** | 「哪几个证候合起来，才能定一个病位/病性」 | 24 个具名判据类（绑定病位/病性） |
| **八纲** | 病位（表/里/半表半里）＋病性（阴/阳、寒/热、虚/实） | 表里、寒热、虚实、阴阳 |
| **六经** | 病位 ⊓ 病性 的六个组合 | 太阳 / 阳明 / 少阳 / 太阴 / 少阴 / 厥阴 |
| **方证** | 「有是证，用是方」——方与证的对应 | 方证名（如「小柴胡汤证」） |
| **方剂/药物** | 母方组成 + 方后注加减 + 兼夹加味 | 最终方名、药味、剂量变化、禁忌提示 |

**为什么必须单向？**（铁律 32、60）

- 八纲**只能由症状推出**，严禁由方证反推（铁律 43）——否则「看到桂枝汤证就倒推表虚」，
  推理链会自我循环，失去可验证性。
- 六经**只能由八纲推出**，方证**只能由六经＋症状推出**。下游不得反推上游。

## 三、四诊采集（业务输入）

### 3.1 四诊通道

| 通道 | 内容 | 本体规模 |
|---|---|---|
| **症状** | 发热、恶寒、腹满、下利、口渴、往来寒热…… | 593 个实例个体 |
| **脉象** | 浮、沉、迟、数、弦、洪大、微细、沉微…… | 68 个实例个体 |
| **舌象** | 舌红、舌淡、苔白、苔黄燥、苔白滑…… | 72 个实例个体 |
| **腹证** | 心下痞硬、胸胁苦满、腹满拒按…… | 4 个实例个体 |

合计 **737 个四诊实例个体**，另配 **1231 条口语同义词**（SKOS 词表），
使「两边肋骨下面胀痛」这类口语也能映射到规范名「胸胁苦满」。

### 3.2 自然语言 → 四诊个体

临床医师/患者用**自然语言**描述，系统分三层映射：

1. **确定性检索**：精确名 → 同义词 → 包含/子串/超串 → 字符模糊；
2. **语义映射**：把**候选白名单**交给大模型，只允许从白名单中选（防幻觉）；
   窄候选集覆盖不到「语义远距」表述时，升级为**全目录候选**再选一次；
3. **置信度门控**：≥0.85 直接采纳；≥0.50 采纳但标记待确认；<0.50 不采纳并列入「未识别」。

> **业务约定**：同义词的唯一权威来源是 **SKOS 词表**（`tcm-zhengzhuang_skos.ttl`）。
> 新增/修正口语说法**只改词表，不改代码**（铁律 61）。

### 3.3 四诊参合的矛盾检测

录入后先做**矛盾检测**：若同时出现**一定互斥**的两项（如「恶寒」与「不恶寒」、
「浮脉」与「沉脉」、「大便硬」与「下利」），判为**四诊参合矛盾**，直接终止并提示
「无法给出诊断」，而非强行往下推。

> 互斥关系收在**互斥模块**（`huchi`，49 对 `owl:disjointWith`），且**只收「一定互斥」者**
> （铁律 64）。互斥公理**不进入推理模块**——否则矛盾四诊会让推理机判本体不一致而中断全流程。

## 四、判据：从四诊到八纲的「桥」

### 4.1 为什么需要判据层

八纲（表里寒热虚实阴阳）是**抽象类**，患者不可能直接报告「我是里证」。
从「腹满、食不下、脉弱」到「里证」，中间需要一条**合取证据**：

> 腹满 **且** 脉弱/微/虚/沉/迟  ⟹  里证（里虚寒）

这条合取证据就是**判据**（Panju）。系统把每个判据建成**具名类**，
`Panju_B8 ⊑ 里证`——即「满足 B8 的患者，必属里证」。

### 4.2 判据清单（38 个，按病位/病性分组）

| 组 | 数量 | 目标 | 代表判据（依据条文） |
|---|---|---|---|
| **A 组** | 9 | 表证（Biao） | A1 脉浮+头项强痛+恶寒（1 条）；A2 发热+汗出+恶风+脉浮缓（12 条）；A3 恶寒+发热+身疼痛+无汗+脉浮紧（35 条）；A7 无热恶寒（7 条，兼 ⊑ 阴）；A8 但欲寐+脉微细（281 条） |
| **B 组** | 8 | 里证（Li） | B1 腹满+吐+食不下+自利益甚（273 条太阴）；B2 大便硬+腹满拒按+潮热+谵语；B3 大热+大汗+大渴+脉洪大（兼 ⊑ 阳）；B7 口渴+洪/大脉/黄苔（26、168、186 条，兼 ⊑ 阳）；B8 腹满+弱/微/虚/沉/迟脉（273 条） |
| **C 组** | 7 | 半表半里（Banbiaobanli） | C1 口苦+咽干+目眩（263 条，兼 ⊑ 热）；C2 往来寒热+胸胁苦满+默默不欲饮食+心烦喜呕（96 条）；C5 消渴/气上撞心/心中疼热/饥而不欲食（326 条厥阴）；C6 往来寒热+胸胁苦满（96 条，兼 ⊑ 阳） |
| **D 组** | 8 | 阳证（Yang） | D1 脉洪大+大热+大汗+大渴；D2 脉浮紧+发热+恶寒+无汗；D4 潮热+谵语+大便硬+腹满拒按；D7 发热+恶寒（7 条「发于阳」）；D8 恶寒+脉浮（1 条太阳提纲，补病性=阳） |
| **E 组** | 6 | 阴证（Yin） | E1 脉微细+但欲寐（281 条少阴提纲）；E2 脉沉微+手足厥冷+下利清谷（317 条）；E4 脉沉迟+下利+腹满时痛；E5 脉微欲绝+四肢逆冷+烦躁（317 条通脉四逆汤） |

> **其中 24 个判据同时绑定「病位」**（A 组 9 + B 组 8 + C 组 7），
> 是六经「病位×病性」配对消解的依据（见 §6.3）。

### 4.3 判据的设计铁律

- **禁止单症状/单脉象直接 ⊑ 八纲**，一律用**合取判据**（铁律 46）——
  单症状不足以定病位/病性，必须合参。
- 每个判据都必须能指出**医书出处**（`rdfs:comment` 中写明依据条文），
  无出处不得写入（铁律 63）。
- 判据是**具名类 + ⊑ 目标八纲**，八纲本身**不写等价类**（D1 设计）。

## 五、八纲：病位与病性

### 5.1 八纲的临床含义

| 维度 | 取值 | 临床含义 |
|---|---|---|
| **病位** | 表 / 里 / 半表半里 | 病邪所在的层次 |
| **病性·寒热** | 寒 / 热 | 机体反应的性质 |
| **病性·虚实** | 虚 / 实 | 正邪力量的对比 |
| **病性·总纲** | 阴 / 阳 | 以上病性的总概括 |

八纲在本体中是 **9 个原子类**：`Biao`（表证）、`Li`（里证）、`Banbiaobanli`（半表半里）、
`Han`（寒证 ⊑ 阴）、`Re`（热证 ⊑ 阳）、`Xu`（虚证 ⊑ 阴）、`Shi`（实证 ⊑ 阳）、
`Yang`（阳证）、`Yin`（阴证）。

### 5.2 阴阳总纲的临床判定（关键医理）

阴阳是八纲总纲，本应由病性决定（热/实属阳，寒/虚属阴）。
**但表证的阴阳另有规定**（胡希恕《六经八纲》）：

- **表阳证 = 太阳病**（虽有表虚，仍属阳）；
- **表阴证 = 少阴病**；
- 二者以 **281 条少阴提纲「脉微细，但欲寐」** 为别，**不以虚实论**。

系统的「阴阳消解」据此：

1. **纯表证**（病位只有「表证」）：若少阴提纲判据成立 → 阴（少阴）；否则 → 阳（太阳）。
2. **其余**（含里证或半表半里）：热证 → 阳；寒证 → 阴；实证 → 阳；虚证 → 阴；皆无 → 阳。

## 六、六经：病位 ⊓ 病性

### 6.1 六经的临床含义

六经不是六个孤立的「病」，而是**病位与病性的六个组合**：

| 六经 | 病位 | 病性 | 提纲条文 |
|---|---|---|---|
| **太阳病** | 表 | 阳 | 1 条「脉浮，头项强痛而恶寒」 |
| **阳明病** | 里 | 阳 | 180、182、208 条 |
| **少阳病** | 半表半里 | 阳 | 263 条「口苦，咽干，目眩」 |
| **太阴病** | 里 | 阴 | 273 条「腹满而吐，食不下，自利益甚」 |
| **少阴病** | 表 | 阴 | 281 条「脉微细，但欲寐」 |
| **厥阴病** | 半表半里 | 阴 | 326 条「消渴，气上撞心，心中疼热」 |

### 6.2 合病

多经同时为病称**合病**。系统识别：三阳合病、太少两感，以及两经合病
（太阳阳明 / 太阳少阳 / 少阳阳明 / 太阳太阴 / 少阳太阴 / 太阴少阴 / 少阴厥阴 等），
未列出的多经组合按「太阳→阳明→少阳→太阴→少阴→厥阴」顺序拼接「X Y 合病」。

### 6.3 交叉积消解（临床易错点）

**问题**：病位之间、病性之间**未声明互斥**，故患者同时具备 ≥2 病位与 ≥2 病性时，
推理机会推出「病位×病性」的**完全交叉积**伪影。

> 例：柴胡桂枝干姜汤证（147 条）患者八纲 = 半表半里+里+虚+阳+阴，
> 交叉积会推出**少阳/厥阴/阳明/太阴四经**，而实际当为「**少阳太阴合病**」。

**医理依据**：病性与病位并非自由组合，而由**判据绑定**——
判据类同时 ⊑ 病位与 ⊑ 病性者即锁定该组合：

- `Panju_C6`（往来寒热+胸胁苦满）⊑ 半表半里 ⊓ 阳 → 半表半里配阳 = **少阳**；
- `Panju_B8`（腹满+虚寒脉）⊑ 里 → 里配阴 = **太阴**。

**算法**（仅当推出的六经恰为完全交叉积时启用；单经、正常合病、三阳合病等「部分交叉」原样返回）：
按判据绑定重新配对，未被绑定的病位与剩余病性稳定配对。

> **业务铁律**：六经提纲证**不足以反推病位**（铁律 35）；合病方证的六经**只能写注解**，
> 不能写等价类，否则会交叉推出 4 个六经（铁律 41）。

## 七、方证：方与证的对应

### 7.1 「有是证，用是方」

方证是**方剂与证候的对应关系**，是经方体系的核心。系统共 **265 个方证**，
按六经分册（太阳 / 少阳阳明 / 少阴太阴 / 厥阴 / 杂病 / 独立 / 合病 / 方根）。

### 7.2 结果形态三态（业务上「敢不敢下结论」）

| 形态 | 条件 | 业务语义 |
|---|---|---|
| **CONFIRMED** | 完全命中 1 个方证 | 给出结论，并说明命中了哪个主证 |
| **CONFIRMED_MULTI** | 完全命中多个 | 按符合度排序，Top1 为结论，其余作并列候选 |
| **NO_MAIN_MATCH** | 零命中 | **方证未定**——候选不得冒充结论 |

> **硬约束**（铁律 16）：只有**完全命中方证的充要定义**才算诊断结论。
> 部分匹配只能作「候选/或然」，绝不能包装成结论。这是「不硬凑」的业务底线。

### 7.3 方证父子层级

依「方随证转、随证加减」，母方与子方得分接近时**优先子方**
（白虎汤类、柴胡汤类、理中汤类、栀子豉汤类、半夏泻心汤类）。

## 八、无结论时的双路径（临床追问）

当 `NO_MAIN_MATCH`（方证未定）时，系统生成两条路径（`analyzeGaps`）：

### 8.1 路A：追问（还缺什么）

两层缺口：

1. **判据缺口**——补哪些四诊发现，能定八纲/六经；
2. **方证主证缺口**——补哪些四诊发现，能定方证。

约束：

- 只对**缺口 ≤ 2 项**的方证生成（`GAP_MAX = 2`），避免「要补十项」的无效追问；
- **剔除抽象类**——八纲、六经**严禁**作为追问选项暴露给用户（铁律 62）；
- **互斥过滤**——与已输入症状互斥者不得作为追问选项（铁律 64.2）。

> **业务铁律 62**：追问的输入**只能是四诊发现**。患者不可能报告「你是里证吗」，
> 任何抽象缺口都必须先**翻译成能推出它的四诊发现**再追问。

### 8.2 路B：或然症候选（可能是哪些方证）

列出「部分匹配」的方证及其**或然症**（`evidence = POSS_ONLY`），
**永不写入结论**，仅供医师参考。

### 8.3 自洽性

追问卡片恒满足 `已命中 + 缺口 == 所需`（全选即命中），保证「按提示补全就能得出结论」。

## 九、兼夹证与加减（随证治之）

### 9.1 兼夹证（加味来源）

兼夹证是主证之外的**兼见病机**，共 8 类：瘀血证、痰饮证、气郁证、痰热/湿热证、
痞满/食积证、兼水饮、兼瘀血、兼食积。其 `addHerbs` 注解在方剂阶段被读取为**加味药物**。

### 9.2 方后注加减

《伤寒论》方后注（「若……者，加……」「不……者，去……」）被编译为**规则引擎**
（`rules.owl`，**46 方证 / 84 条规则**）：

- 规则形式：`IF <症状合取> THEN 去 X + 加 Y（剂量）…`，附**条文出处**；
- 多条规则可同时命中；
- 加减后做**配伍禁忌检查**（如十八反），命中则给出 `warnings`。

### 9.3 药证兜底

无规则命中、且症状超出主证范畴时，启用**药证**（52 个药证 / 86 个条件键）兜底加味。

## 十、典型临床路径举例

### 例 1：太阴里虚寒（理中汤证）

```
输入：腹满，食不下，自利，脉弱
判据：Panju_B1（腹满+吐+食不下+自利益甚，273 条）、Panju_B8（腹满+弱脉）
八纲：里证 + 阴证（虚寒）
六经：太阴病
方证：理中汤证（CONFIRMED）
方剂：理中汤（人参、干姜、白术、甘草）
依据：《伤寒论》273、277、386 条
```

### 例 2：少阳太阴合病（柴胡桂枝干姜汤证）

```
输入：往来寒热，胸胁满微结，小便不利，渴而不呕，但头汗出，心烦
判据：Panju_C6（往来寒热+胸胁苦满）、Panju_B8（腹满+虚寒脉）
八纲：半表半里 + 里 + 虚 + 阳 + 阴
六经：少阳太阴合病（交叉积消解后，非少阳/厥阴/阳明/太阴四经）
方证：柴胡桂枝干姜汤证（CONFIRMED）
依据：《伤寒论》147 条
```

### 例 3：信息不足（方证未定 → 追问）

```
输入：头晕，乏力
结果：NO_MAIN_MATCH（方证未定）
路A 追问：① 是否「心下悸、小便不利」（定水饮/少阴）？② 是否「脉沉细」？
路B 或然症候选：真武汤证（部分匹配）、苓桂术甘汤证（部分匹配）……
```
