## 二、机制：为什么会出现「六经推不出 → 方证未定」

诊断链路严格单向（铁律 60）：

```
四诊发现 → 判据(Panju_A1..E6) → 八纲 → 六经(≡病位⊓病性) → 方证
```

**方证等价类的结构**（本体 `ontology/fangzheng/*.owl`）：

```xml
<owl:equivalentClass>
  <owl:Class><owl:intersectionOf rdf:parseType="Collection">
     <owl:Class rdf:about="#Taiyangbing"/>                              <!-- 六经 -->
     <owl:Restriction>...you_zhengzhuang...Shentengfan</owl:Restriction> <!-- 四诊 -->
     <owl:Restriction>...you_maixiang...Chenchimai</owl:Restriction>
  </owl:intersectionOf></owl:Class>
</owl:equivalentClass>
```

即 **方证 ≡ 六经 ⊓ 四诊**。六经推不出 ⇒ 方证等价类必不匹配 ⇒ 判「方证未定」。

**测试框架的「六经锚点注入」**（`JingfangTestSupport.assertFangzheng`）：
用例只给方证主证（少量四诊），不足以推出六经，故框架按 `lj` 注入该六经的
「粗粒度近似四诊」：

| 六经 | 锚点症状 | 锚点脉象 |
|---|---|---|
| 太阳 | 恶寒 | **浮脉** |
| 阳明 | 口渴 | **洪脉** |
| 少阳 | 往来寒热、胸胁苦满 | 弦脉 |
| 太阴 | 腹满 | 弱脉 |
| 少阴 | 但欲寐 | **沉微脉** |
| 厥阴 | 消渴、手足冷 | 微细脉 |

**关键约束**（铁律 64）：若锚点四诊与病例自身四诊**互斥**，则跳过该锚点
（`conflicts()` 查互斥索引），以免构造出临床不可能的四诊组合。

**互斥索引**（`tcm-huchi.owl` + 子类闭包展开）中与本次相关的只有 4 对脉象：
`浮⊥沉`、`洪⊥微`、`滑⊥涩`、`浮⊥伏`。

**脉象层级**（`tcm-maixiang.owl`）：

```
浮脉 ⊑ 表
沉脉 ⊑ (无八纲)          沉迟脉 ⊑ 沉脉,寒      沉微脉 ⊑ 沉脉,微脉,虚
沉紧脉 ⊑ 沉脉,紧脉,实    微细脉 ⊑ 微脉,细脉,虚  微弦脉 ⊑ 微脉,弦脉,虚
洪脉 ⊑ (无八纲)          弱脉 ⊑ 虚
```

于是矛盾产生的**唯一机制**是：

> 锚点脉象与病例脉象互斥 → 锚点被跳过 → 该六经的病位/病性证据缺失
> → 六经推不出 → 方证等价类不匹配 → 方证未定。

## 三、根因五类（21 例）

### 类① 篇章归属 ≠ 八纲归属（4 例）—— 本体自相矛盾，最硬的一类

这 4 例的 `belongsToLiujing`（篇章归属）与 `bagangAttr`（八纲归属）**在本体内直接打架**：

| 方证 | belongsToLiujing（篇章） | bagangAttr（八纲） | 等价类首元素 |
|---|---|---|---|
| 大陷胸汤证 | 太阳 | 里+阳+实+热 = **阳明** | `cls:Taiyangbing` |
| 三物白散证 | 太阳 | 里+阴+实+寒 = **太阴** | `cls:Taiyangbing` |
| 茯苓桂枝白术甘草汤证 | 太阳 | 里+阴+虚+寒 = **太阴** | `cls:Taiyangbing` |
| 桂枝茯苓丸证 | 太阳 | 里+阴+实 = **太阴** | `cls:Taiyangbing` |

按铁律 22，`belongsToLiujing` 只是**篇章位置**（这些方证都写在太阳病篇/太阳类），
而 `bagangAttr` 才是**八纲归属**。等价类却用了篇章六经（太阳）当必要条件 →
把「篇章位置」当成了「诊断必要条件」。

**与十枣汤先例完全同型**（铁律 65 实例）：十枣汤证原 `lj=太阳`，
胡希恕判「结胸属阳明里实」，改为 `阳明` 后经 `Panju_B7`（口渴+洪脉）自然推出阳明，
矛盾于源头消除。**大陷胸汤证同为结胸**，`bagangAttr` 已是「里阳实热」，应同法改阳明。

### 类② 太阳锚点「浮脉」与病例沉脉互斥（8 例）

`lj=太阳`、`bagangAttr` 亦为表阳（**六经归属正确**），但病例脉象为沉/沉迟/沉弦，
与太阳锚点浮脉互斥 → 浮脉被跳过 → 表/阳证据缺失 → 太阳推不出。

| 方证 | 病例四诊 | 病例脉 | 锚点跳过 |
|---|---|---|---|
| 桂枝新加汤证（62条） | 身疼烦+恶寒 | 沉迟脉 | 浮脉 |
| 桂枝加桂汤证（117条 奔豚） | 气从少腹上冲心 | 沉迟脉 | 浮脉 |
| 桂枝加黄芪汤证（金匮 黄汗） | 黄汗+两胫自冷+… | 沉脉 | 浮脉 |
| 甘草麻黄汤证（金匮 里水） | 里水 | 沉脉 | 浮脉 |
| 黄芪芍药桂枝苦酒汤证（金匮 黄汗） | 黄汗+身肿+发热+汗出+口渴 | 沉脉 | 浮脉 |
| 栝蒌桂枝汤证（金匮 痉病） | 身体强几几+发热+汗出+恶风 | 沉迟脉 | 浮脉 |
| 桃核承气汤证（106条） | 少腹急结+如狂 | 沉脉+涩脉 | 浮脉 | **已改判阳明（见第六节）** |
| 茯苓桂枝甘草大枣汤证（65条） | 脐下悸+欲作奔豚 | 沉脉 | 浮脉 |

**难点**：太阳的病位证据在本体内**只有浮脉一条路**（`浮脉⊑表`；
A1/A2/A3/A6 皆含浮脉；D8 需恶寒+浮脉）。沉脉按铁律 36④**不挂里**，
所以这些病例的沉脉既不给表、也不给里 → 病位悬空。
**这一类无法靠改锚点解决**，需要结构性决策（见第五节）。

### 类③ 少阴锚点「沉微脉」与病例浮脉互斥（4 例）

少阴咽痛四方证（310–313条），`lj=少阴`、`bagangAttr=表+阴+虚`（**六经归属正确**）。
病例脉象为**浮脉**，与少阴锚点沉微脉互斥（沉微脉⊑沉脉⊥浮脉）→ 沉微脉被跳过；
只剩「但欲寐」，而 `Panju_E1` 需「脉微细+但欲寐」→ 少阴推不出。

| 方证 | 病例 |
|---|---|
| 甘草汤证（310条） | 咽痛，脉浮 |
| 桔梗汤证（311条） | 咽痛+咳嗽+吐脓，脉浮 |
| 半夏散及汤证（313条） | 咽中痛，脉浮 |
| 苦酒汤证（312条） | 咽中伤生疮+不得语，脉浮 |

**关键发现**：少阴提纲（281条）原文是「**脉微细**，但欲寐」——
锚点却用了「沉微脉」。而 `微细脉`（`Weiximai ⊑ 微脉,细脉,虚`）**不与浮脉互斥**。
把少阴锚点脉象由 `沉微脉` 改为 `微细脉`，既**更贴合 281 条原文**，
又能让这 4 例经 `A8`（但欲寐+脉微细→表）+ `E1`（脉微细+但欲寐→阴）自然推出少阴。

### 类④ 阳明锚点「洪脉」与病例微脉互斥（1 例）

鸡屎白散证（金匮 转筋），`lj=阳明`、`bagangAttr=里+阳+实+热`（**归属正确**）。
病例脉象为**微弦脉**（`Weixianmai ⊑ 微脉,弦脉,虚`），与阳明锚点洪脉互斥（洪⊥微）
→ 洪脉被跳过 → `Panju_B7`（口渴+洪/大/黄苔）不触发 → 阳明推不出。

### 类⑤ 合病 / 推导不符（4 例）

| 方证 | 期望 | 实际 | 说明 |
|---|---|---|---|
| 乌头桂枝汤证（金匮 寒疝） | 含太阳 | 阳明+太阴 | `lj=太阳+太阴`，`bagangAttr=表+里+阴+实+寒`；实得阳明+太阴，缺太阳 |

## 五、待裁定：类② 的结构性决策

类② 的 8 例，六经归属（太阳）**医理正确**，但病例四诊（沉脉）**推不出表阳**——
因为太阳的病位证据在本体内只有「浮脉」一条路，而沉脉按铁律 36④ 又不挂里。
三条可选路线：

**路线 A（改锚点）**：给太阳锚点补一条不含浮脉的表证路径。
需新增判据（如「恶寒+身疼痛→表」），**必须有医书依据**（铁律 63），否则不可写。

**路线 B（改等价类结构）**：方证等价类**不再要求六经**，改为「八纲 ⊓ 四诊」或「仅四诊」，
六经作为独立输出。最贴合铁律 22（六经是篇章归属，本不该当诊断必要条件），
但改动面最大，且与十枣汤先例（保留六经于等价类）取向不同。

**路线 C（改期望/输入）**：承认这些方证的四诊不足以定六经，测试期望改为「六经难定」，
或补足能推出太阳的四诊（但会与病例脉象冲突，不可行）。

**建议**：先执行类①③④⑤（13 例，医理判定明确），再单独决策类②。

## 六、执行结果（2026-09-22 收尾）

### 6.1 类② 的落地方式：太阳锚点「无脉替代症状」fallback

类② 8 例按**路线 A** 落地，但实现方式不是新增判据，而是给测试框架
`JingfangTestSupport` 增加 **`LJ_ANCHOR_PULSE_FALLBACK_SYMPTOMS`**：

> 当某经的**脉象锚点全部被跳过**（脉路彻底断绝）时，改用**不依赖脉象**的替代症状注入。
> 太阳 → `[项强(Xiangqiang), 发热(Fare)]`。
> - 定「表」：`Xiangqiang ⊑ Biao` 是既有定义性公理（《伤寒论》1条「头项强痛而恶寒」）。
> - 定「阳」：`Panju_D7`（恶寒+发热）——《伤寒论》3条「或已发热，或未发热，必恶寒」。
> - **仅在脉路断绝时注入**：病例自带浮脉时 `Panju_D8` 已能定阳，再注入发热会平白抬高桂枝汤证，
>   把小青龙汤证挤成麻黄汤证、桂枝加葛根汤证挤成桂枝汤证（实测）。

效果：类② 8 例中 **7 例**经此机制自然通过（六经可推出 → 方证 gap=0）。

### 6.2 桃核承气汤证：改判阳明（类① 同型，铁律 65 裁定）

**残留矛盾**：fallback 注入的「发热」＋病例自带的「沉脉」恰好构成 301 条少阴病
（`Mahuangfuzixixintangzheng ≡ Shaoyinbing ⊓ Fare ⊓ Chenmai`）的完整签名；
而「涩脉 ⊑ 虚 ⊑ 阴」提供了「表阴」所需的阴证 →
患者六经 = 太阳 + 少阴（太少两感）→ 麻黄附子细辛汤证与桃核承气汤证
**五元组全同**（`hits=4/4, gap=0, poss=0/0, prio=2`）→ 落到字典序 → 误选前者。

**对照**：同类的大陷胸汤证（沉紧脉）能通过，正因 `沉紧脉 ⊑ 实`（阳），不产生阴证 → 无少阴竞争。

**医书判定（哪一方错）**：

| 依据 | 原文 | 结论 |
|---|---|---|
| 《伤寒论》106条 | 「太阳病不解，热结膀胱，其人如狂……**其外不解者，尚未可攻，当先解其外；外解已，但少腹急结者，乃可攻之**，宜桃核承气汤」 | 「外解已……乃可攻之」明言本方用于**表已解之后**，病位在**里** |
| 《伤寒论》125条（抵当汤） | 「小便自利，其人如狂者，**血证谛也**」并「**脉沉结**」 | 蓄血属**里实**（沉脉有据） |
| 胡希恕《经方方证传真》 | 蓄血证判「**血瘀里实**」 | 里实 |
| 方剂构成 | 桃核承气汤 = 调胃承气汤（阳明里实）＋桂枝、桃仁 | 主治**里实热**之蓄血 |

→ **本体错**：`belongsToLiujing=Taiyangbing` 与 `bagangAttr` 自身已含 `Li` 相矛盾；
列于太阳病篇仅为**条文体例**（铁律 22）。与十枣汤证（152条「表解里未和」→ 改阳明）**完全同型**。

**修正动作**（`ontology/fangzheng/shaoyang_yangming.owl`）：

| 项 | 改前 | 改后 |
|---|---|---|
| `belongsToLiujing` | `Taiyangbing` | `Yangmingbing` |
| `bagangAttr` | Biao, Li, Yang, Shi, Re | **Li, Yang, Shi, Re**（撤 Biao） |
| `equivalentClass` 首元素 | `Taiyangbing` | `Yangmingbing` |
| `ruleSource` | 无 | **新增**（106/125条原文＋胡希恕按语，铁律 65.3） |
| 测试期望（`ShaoyangYangmingFangzhengTest#t_taohechengqitang`） | `"Taiyangbing"` | `"Yangmingbing"` |

**改后诊断**（锚点走阳明「口渴＋洪脉」，洪⊥微 不与沉脉互斥，**不再触发 fallback**）：

```
八纲：{表里=[里证], 虚实=[虚证], 阴阳=[阴证, 阳证]}
六经：阳明太阴合病（列表 [太阴病, 阳明病]）
方证：桃核承气汤证（hits=4/4, gap=0, prio=2）
推荐方剂：桃核承气汤 ｜ 药物：[大黄, 甘草, 桂枝, 芒硝, 桃仁]
```

麻黄附子细辛汤证因**无表证**（锚点已改阳明，不再注入项强/发热）而不再成立 → 竞争消失。
