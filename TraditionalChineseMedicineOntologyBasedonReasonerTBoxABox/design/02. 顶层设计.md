# 经方诊疗本体设计与应用（Openllet 推理机）

> 作者：张仲景 & 胡希恕（模拟）  
> 原则：先辨六经，继辨八纲，再辨方证，乃至药证  
> 推理机：Openllet（支持 OWL 2 DL + SWRL）

---

## 一、总体流程

1. **本体构建（TBox）**  
   - 定义顶层类：四诊信息、六经病、八纲、方证、方剂、药物、药证。  
   - 定义对象属性：`has_symptom`、`has_pulse`、`has_prescription` 等。  
   - 定义八纲、六经、方证的等价公理。  
   - 定义方剂、药物、药证的实例与关系。  
   - 可选定义 SWRL 规则处理合病、并病、加减变化。

2. **患者录入（ABox）**  
   - 以个体形式录入四诊信息（症状、脉象、舌象、腹证等）。

3. **推理诊断**  
   - Openllet 执行一致性检查，确保四诊信息无矛盾。  
   - 自动分类：将患者归入八纲 → 六经 → 方证 → 方剂。  
   - 触发 SWRL 规则（如有），得出加减方或合病处理。

4. **输出结果**  
   - 给出病、证、方、药及条文依据，并可追溯推理路径。

### 2.2 对象属性

| 属性 | 定义域 | 值域 | 说明 |
|------|--------|------|------|
| `has_symptom` | 患者 | 症状 | 患者表现出某症状 |
| `has_pulse` | 患者 | 脉象 | 患者脉象 |
| `has_tongue` | 患者 | 舌象 | 患者舌象 |
| `has_abdominal_sign` | 患者 | 腹证 | 患者腹证 |
| `has_prescription` | 方证 | 方剂 | 方证对应方剂 |
| `has_ingredient` | 方剂 | 药物 | 方剂组成药物 |
| `has_indication` | 药物 | 药证 | 药物的适应证（药证） |

### 2.3 八纲公理

```manchester
Class: 表证
  EquivalentTo: 
    (has_symptom some 恶寒 or has_symptom some 恶风) 
    and (has_pulse some 浮)

Class: 里证
  EquivalentTo: 
    has_symptom some (腹满 or 便秘 or 下利 or 呕吐 or 口渴)
    and (not 表证)

Class: 热证
  EquivalentTo: 
    has_symptom some 发热
    and (has_symptom some 口渴 or has_symptom some 烦躁 or has_pulse some 数)

Class: 寒证
  EquivalentTo: 
    has_symptom some 恶寒
    and (has_pulse some 迟 or has_symptom some 下利清谷 or has_symptom some 手足厥冷)

Class: 表虚证
  EquivalentTo: 表证 and has_symptom some 汗出

Class: 表实证
  EquivalentTo: 表证 and has_symptom some 无汗

Class: 里虚证
  EquivalentTo: 里证 and has_symptom some 下利 and has_symptom some 食不下

Class: 里实证
  EquivalentTo: 里证 and (has_symptom some 便秘 or has_symptom some 腹满硬痛)

Class: 阳证
  EquivalentTo: 表证 or 热证 or 实证

Class: 阴证
  EquivalentTo: 里证 or 寒证 or 虚证
```

### 2.7 药证与药物关联（示例）

```manchester
Class: 桂枝证
  EquivalentTo: 
    (has_symptom some 汗出) 
    and (has_symptom some 恶风) 
    and (has_pulse some 浮缓) 
    and (has_symptom some 气上冲)

  Types: has_indication some 桂枝证

Class: 葛根证
  EquivalentTo: has_symptom some 项背强几几

Individual: 葛根
  Types: has_indication some 葛根证
```

### 2.8 SWRL 规则（示例）

```swrl
// 太阳中风兼项背强几几，用桂枝加葛根汤
患者(?p) ^ 类型(?p, 桂枝汤证) ^ has_symptom(?p, 项背强几几) -> 类型(?p, 桂枝加葛根汤证)

// 太阳阳明合病，喘而胸满者，麻黄汤主之（简化示例）
患者(?p) ^ 类型(?p, 太阳病) ^ 类型(?p, 阳明病) ^ has_symptom(?p, 喘) -> 类型(?p, 麻黄汤证)
```
