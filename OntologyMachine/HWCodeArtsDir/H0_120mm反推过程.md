# 通过 120mm 约束反推 H_0 的推导过程

> 说明：本文档记录 LatticeTower 程序当前实现的「120mm 约束 → H_0」反推链路，
> 对应源码 `LatticeTowerOntologyJobWorker.computeFeasibleSolutions`（L459–481）。
> 示例参数：`bw=25m、β=47.7°、top=9800mm、H=115253mm、dev=500mm、firstOff=120mm`。
> 目的：定位 H_0 / dev_1 的 1.93mm 残差，供口径澄清与后续修改参考。

## 第 0 步：收分几何（塔柱中心线斜率）

塔柱中心线由 `(bw, top, H)` 唯一确定：

- `dxHalf = (bw − top) / 2 = (25000 − 9800) / 2 = 7600`
- `lineLen = √( (√2·dxHalf)² + H² ) = √(10748.0² + 115253²) = 115753.6`
- **`b = (top − bw) / (2H) = (9800 − 25000) / (2 × 115253) = −0.0659416`**（`dx/dz`，负值＝向上收窄）
- `α = acos(dxHalf / lineLen) = 86.236°`（中心线与 −x 轴夹角）

## 第 1 步：斜腹杆的「有效斜率」eff（含 y 向收分的真实三维角）

```
t   = tanβ = tan(47.7°) = 1.0991
eff = t / √(1 − b²·t²) = 1.10199
```

分母 `√(1 − b²t²)` 是把「斜腹杆与水平面的真实三维夹角 β」折算成**立面内 dz/dx 斜率**的收分修正项。

## 第 2 步：120mm 约束 → P₁₂₀ 的竖直高度 z₁

口径：**P₁₂₀ = 斜腹杆起点沿杆反向延长 ∩ 同侧外侧塔柱中心线**；
120mm = P₁₂₀ 到「斜腹杆所在斜面 ∩ 塔底平面」交线的**垂线长**。

该交线是水平线，中心线上高度为 z 的点到它的垂距满足：

```
d = z · √(1 + b²)
```

令 `d = 120`：

```
z₁ = firstOff / √(1 + b²) = 120 / √(1 + 0.0043483) = 119.740
```

## 第 3 步：沿斜腹杆从 P₁₂₀ 升到偏心线交点 dev₁ → 竖直升高 Δ

P₁₂₀ 与 dev₁ 分别落在**中心线**与**平行于中心线的偏心线**上（两线都随高度倾斜、斜率 b），
斜腹杆斜率 eff。两平行斜线间的严格竖直升高含分母修正：

```
Δ = dev · eff / (1 + b · eff)
  = 500 × 1.10199 / (1 + (−0.0659416)(1.10199))
  = 500 × 1.10199 / 0.92733
  = 594.110
```

## 第 4 步：首个偏心节点 dev₁ 的高度

```
dev₁ = z₁ + Δ = 119.740 + 594.110 = 713.850
```

## 第 5 步：dev₁ → H_0（加上偏心偏移的竖直分量 Δₘ）

H₀ 取「**主立柱（非偏移）节点**」高度（中心线节点），需把 dev₁ 沿偏心方向平移回中心线，
竖直分量为：

```
Δₘ = dev · tan(π/2 − α) = dev · cotα = 500 × 0.065799 = 32.899
H_0 = dev₁ + Δₘ = 713.850 + 32.899 = 746.749
```

## 数值追踪（bw=25 / β=47.7）

| 步 | 量 | 值 |
|---|---|---|
| 0 | b | −0.0659416 |
| 0 | α | 86.236° |
| 1 | eff | 1.10199 |
| 2 | z₁（P₁₂₀ 高） | 119.740 |
| 3 | Δ | 594.110 |
| 4 | dev₁ | 713.850 |
| 5 | Δₘ | 32.899 |
| 5 | **H_0** | **746.749** |

## 与基准的差（残差定位）

- 客户 CAD 实测基准：`H_0 = 744.817`（对应 `dev₁ = 711.9177`）。
- 程序：`H_0 = 746.749`，**偏 +1.932**，且该偏差 **100% 落在第 3 步的 Δ**：
  - 程序 `Δ = 594.110`；按 dev₁ = 711.9177 反推应为 `Δ = 592.178`（差 +1.932）。
- 其余各步已证实无偏差：
  - `z₁ = 120 / √(1+b²)` 可由几何严格导出；
  - `Δₘ` 与中心线口径一致；
  - `H_0 = dev₁ + Δₘ` 构造本身无误。

## 补充（本轮实算发现的口径疑点）

1. **客户脚本本身没有「120mm」逻辑**——`H_0 = 744.817` 是脚本第 522 行的**硬编码输入**，
   仅用于 `L0 = H_0 / sinγ`。
2. 按客户脚本实跑节点反推，首根斜腹杆反向延长线与柱中心线是**异面直线（最小间隙 2.16mm）**，
   其到「斜面 ∩ 塔底平面」交线的垂距实为 **117.317mm，并非 120mm**。
3. 源文档 `design/客户调研.txt` 自相矛盾：第 11 行称 H_0 = 中心线节点高度；
   第 30 行称 H_0 = 偏心线交点高度。二者相差 Δₘ = 32.899。

以上三点即「120mm → H_0」口径需要向客户澄清的根因（另见 `HWCodeArtsDir/H0口径澄清.md`）。
