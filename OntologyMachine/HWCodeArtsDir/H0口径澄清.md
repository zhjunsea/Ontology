# H_0（首柱主节点高度）口径澄清清单

> 目的：澄清「120mm 约束 → H_0」的确切构造，以便把 LatticeTower 程序对齐客户脚本。
> 背景：交叉点 bug 已修复；当前唯一残差落在**首柱节点基准高度 H_0 / dev_1**（bw=25、β=47.7 时约 1.93mm）。
> 证据脚本：`HWCodeArtsDir/probe_p120b.py`、`repro_customer_script.py`（均只读、不改客户资产）。

## 一、已确证（无争议）

| 量 | 客户脚本实跑 | 程序现值 | 结论 |
|---|---|---|---|
| col_a1（主立柱首节点=H_0）z | **744.817** | 746.7495 | ✗ 差 **+1.9325** |
| dev_1 z | **711.9177** | 713.8500 | ✗ 差 **+1.9323** |
| Δₘ = dev·tan(π/2−α) | **32.8993** | 32.8995 | ✓ 一致 |
| z₁ = firstOff/√(1+b²) | 119.740（由约束得） | 119.740 | ✓ |
| b = (dis_top/2−dis_bott/2)/high | −0.065942 | −0.065942 | ✓ 中心线同一 |

要点：**Δₘ 与中心线口径完全一致**，残差 **100% 来自 H_0 的构造方式**。

## 二、关键发现（需要客户澄清）

1. **客户脚本本身没有"120mm"逻辑**：`H_0 = 744.817` 是脚本第 522 行**硬编码输入**，仅用于 `L0 = H_0/sinγ`。→ 原程序里 H_0 是否也是输入？
2. **按脚本实跑节点做精确 3D 反推**（`probe_p120b.py`）：
   - 首根斜腹杆（`col_a_dev_x1 → col_b_dev_x2`）反向延长线与柱 a 中心线**不相交**，二者为**异面直线，最小间隙 2.1647 mm**；
   - 最近点处 z = **117.063**，该点到「斜腹杆所在面 ∩ 塔底平面」交线的垂距 = **117.317 mm**（**不是 120**）。
   - 由此精确几何得 Δ(P₁₂₀→dev_1) = **594.855 mm**；程序式 `dev·eff/(1+b·eff)` = **594.110 mm**；若要复现 dev_1=711.9177 则需 Δ = **592.178 mm**。三者互不相等，无任一闭式命中 592.178。
3. **源文档自相矛盾**：`design/客户调研.txt` 第 11 行称 H_0 = "中心线节点高度"（=col_a1，与脚本注释一致）；第 30 行称 H_0 = "偏心线交点的高度"（=dev_1）。二者相差 Δₘ=32.899。

## 三、需客户确认的三个问题

- **Q1**：原程序中 H_0（bw=25 时为 744.817）是**输入常量**，还是由"首个斜腹杆 120mm 约束"**反推**得到？
- **Q2**：若为反推，请给出**确切构造步骤**：在哪个平面投影？"该杆所在的平面"如何定义？P₁₂₀ 取"斜腹杆反向延长线与柱中心线的**交点**"还是"**最近点**"？（按脚本实算二者为异面直线，间隙 2.16mm，垂距实为 117.317mm≠120mm。）
- **Q3**：H_0 是否**随底宽 bw 变化**？若是，请提供不同 bw 下的 H_0（或反推规则），以便程序推广到全部底宽；若固定，请确认对所有 bw 均取同一值。

## 三·补、最终裁定（2026-10-29 业务方）

**裁定：以 120mm 为准，不改程序；`H_0=744.817` 视为历史遗留值。**

依据：客户脚本 `H_0=744.817` 为第 522 行**写死输入**，且其几何实测违反 120mm 约束
（第一斜腹杆反向延长线与柱中心线异面、交点垂距 117.317mm≠120mm）。现程序严格满足
120mm（`z₁=120/√(1+b²)`），即正解；1.932mm 残差系参考基准自身不自洽所致，非程序缺陷。
与《LatticeTower应用-测试设计文档》v1.12 结论一致（客户脚本 H_0 无封闭生成式、亚毫米残差不可消除）。

## 四、实现方向（已按上节裁定：不实施）

- 若 Q1 判定"输入"：将 H_0（或 H_0(bw)）作为本体常量读入，程序不再由 120mm 反推。
- 若 Q1 判定"反推"：按 Q2 确认的精确构造重写 `LatticeTowerOntologyJobWorker.java` 的 `firstVert/h0`（:479/481）与 `eff`（:471）。
- 无论哪种，均需先经确认，避免改动歧义代码。
