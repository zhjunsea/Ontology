## 1. A 类问题（与原著相违 / 明确错误）

### A1 「岁运并临」判定对象用错（高）

**代码（`SiZhuBaZiOntologyJobWorker.java` L968–981）：**
```java
int dayIdx = sexagenaryIndex(p[2][0], p[2][1]);      // 日柱
for (int i = 0; i < 10; i++) {
    int y = birthYear + i;
    int yi = floorMod(y - 4, 60);
    if (yi == dayIdx)  special.add(y + "岁运并临");     // ← 拿「流年」比「日柱」
    ...
    if (ygz.equals(ganZhi(p[2])))  special.add(y + "日柱伏吟");
}
```
`yi == dayIdx` 与 `ygz.equals(日柱)` 是**同一条件**，故每逢「流年＝日柱」之年，会被**同时**标为「岁运并临」和「日柱伏吟」。

**原著：** 三命通会·论大运（卷三）：
> 「又如甲子流年又是甲子运，谓之岁运并临，独羊刃、七煞……」（三命通会.txt:3340）

渊海子平亦多处「岁运并临」皆指**流年与大运干支相同**（如「劫财羊刃，切忌时逢，岁运并临，灾殃立至」）。**岁运并临 = 大运干支＝流年干支**，与「日柱」无关。

**判定：** 错误。应改为「大运序列中某一运之干支 == 某流年干支」时判「岁运并临」；流年==日柱应只判「伏吟」（现码已单独判，重复）。

### A2 「羊刃」误配阴干（高）

**代码（L155）：**
```java
private static final int[] YANGREN = {3, 2, 6, 5, 6, 5, 9, 8, 0, 11};
//   甲卯  乙寅  丙午  丁巳  戊午  己巳  庚酉  辛申  壬子  癸亥
```

**原著：** 三命通会·论阳刃（卷五）：
> 「即禄前一位，言旺越其分，故险……**惟甲丙戊庚壬五阳干有刃，乙丁己辛癸五阴干无刃，故曰阳刃。**」（三命通会.txt:10976 起）

渊海子平·论羊刃亦云：
> 「何谓羊刃？**甲丙戊庚壬五阳有刃，乙己丁辛癸五阴无刃，故名阳刃。**」（渊海子平.txt:961）

即**阴干无刃**，只有甲卯、丙午、戊午、庚酉、壬子五位。现码对十干皆配刃，且阴干取「帝旺」（乙寅、丁巳、己巳、辛申、癸亥），既违「五阴无刃」，也与渊海子平另列之阴干刃位（论羊刃条：乙辰、丁未、己未、辛戌、癸丑，即「禄前一辰」）**均不合**。

**影响：** 阴日主（乙丁己辛癸）会被误报「羊刃」，进而污染节点6（神煞）、节点14（寿夭）、节点16（告警「羊刃＋相冲→寿元关」）。

**判定：** 错误。建议改为仅五阳干有刃；若须列阴刃，须单列并注明「异说」，且采用渊海子平「禄前一辰」表而非帝旺表。

### A3 男命子星误配（中高）

**代码（L498–499）：**
> 「……比劫主兄弟，**食伤主子女**。」

**原著：** 渊海子平·论子息：
> 「**男取克干为嗣，女取干生为子**……假令甲乙生人，以庚辛为子息。若女命甲乙生人，以丙丁为子息。」（渊海子平.txt:583）

### A4 用神「主取」名实不符（中高）

**代码（`selectYongShen` L789–797）：**
```java
// 主取（月令格局法）：身强用「克我」（官杀），身弱用「生我」（印绶）
int yongElem = strong ? (dayElem + 3) % 5 : (dayElem + 4) % 5;
...
String yongShen = "用神（主取·月令格局法）：" ...;
```
即：**身强取官杀、身弱取印**——这是**旺衰（扶抑）法**，全程**未使用月令**。

**原著：** 子平真诠·论用神：
> 「**八字用神，专求月令**，以日干配月令地支，而生克不同，格局分焉。财官印食，此用神之善而顺用之者也；煞伤劫刃，用神之不善而逆用之者也。当顺而顺，当逆而逆……」（子平真诠.txt:「八、论用神」）

设计文档《本体核心设计》R11、《应用架构设计》节点9 亦自述「用神专求月令（主取）」。但代码的「主取」实为身强/身弱二选一，**既未依月令，也未依「善神顺用/不善神逆用」**，且只用单一百的（官杀或印），未随格局（如正官格须财/印护官、食神格须身旺/生财等）而定。

**判定：** 名实不符。应改为：以月令所定格神为主取用神，并按「四吉神顺用、四凶神逆用」配相神/忌神；旺衰法作为「并陈」异法保留。

### A5 月令本气十神定格局，土日午月/四库月失准（中）

**代码（`determinePattern` L676–693）：** 取月令地支**本气**藏干之十神定格：本气比肩→建禄格；本气劫财→阳刃格（月劫）；余则「X 格」。

**原著 / 矛盾点：**
1. **戊日午月**：午藏丁己，本气为丁（对戊为**正印**），故现码判「正印格」。然**戊之阳刃在午**（三命通会·论阳刃「甲丙戊庚壬五阳干有刃」；神峰通考·阳刃格「且如**戊日午为刃**」羊刃.txt:299），戊日午月当为**阳刃格**。
2. **土日四库月**：戊日辰/戌月（本气戊）、己日辰/戌月（本气戊）、己日丑/未月（本气己）等，本气为比劫，现码判「建禄格」。但**建禄须月令为日主之禄**（戊禄在巳、己禄在午），辰戌丑未为四库杂气而非禄（子平真诠·论建禄月劫、论墓库刑冲之说）。应循「杂气取用」，非一律建禄。

**判定：** 月令本气十神法在「土日」失准。建议：格局以月令（提纲）为准，但对四库月与土日，需显式处理杂气与阳刃（戊午）。

### B2 外格/杂格未实现，相关引据永不触发（中）

`determinePattern` 只产出八正格名（正官/偏官/正财/偏财/印绶/食神/伤官/阳刃/建禄），**从不产出**「从格/化格/专旺/曲直/炎上/稼穑/从革/润下」。而 `citeDts`（L1789–1808）却按 `pattern.contains("从"/"化"/"专旺"/"曲直"…)` 去取《滴天髓》象论——**这些分支在运行期永不命中**。与设计文档《流程设计》第 8 节点「格局判定含外格/杂格（从格/化格/专旺/禄马类）」不符。

**判定：** 覆盖缺口。或补实现外格判定，或修正文档与引据分支。

### B3 「命宫」起例与三命通会所载不合（中）

**代码（`mingGong` L2599–2603）：**
```java
int sum = (monthBranch + 1) + (hourBranch + 1);
int gong = (sum <= 14) ? (14 - sum) : (26 - sum);
return ZHI[floorMod(gong - 1, 12)];
```

**原著：** 三命通会·论坐命官：
> 「先将所生之月从子上起正月，亥上二月，戌三……逆行十二位，次将所生之时加于所生之月，顺行十二位，**逢卯即安命宫**。假令甲子年三月生人得戌时……即命坐**卯**宫是也。」（三命通会.txt:3152–3187）

以原著所举例（三月、戌时 → 命宫**卯**）回代现码：辰月（index 4）、戌时（index 10），`sum=(4+1)+(10+1)=16` → `26-16=10` → `ZHI[9]=酉`，**得酉非卯**。

**判定：** 不符。宜按原著「子起正月逆行、时加月宫顺行逢卯安命」重写；文档已标「异说并陈」，但引据既指向三命通会，即以该书起例为准。

### B4 「小运」法与所引篇目不符（低中）

**代码（L316）：** 小运 = `greatFortunes(hp, direction, 8)`，即**自时柱起、顺逆行**（醉醒子法）。文档引据为「三命通会·论小运 / 渊海子平·论行小运法」。

**原著：** 三命通会·论小运：
> 「古人以**男起丙寅顺行，女起壬申逆行**，一定而不可易也……醉醒子以为男女小运皆由时生而行之，逆顺亦以年定。」（三命通会.txt:3255）

即**古法为男丙寅/女壬申**，「由时生而行之」是醉醒子的**另一种**说法。现码取后者，却引前者篇目，标注不严密。

**判定：** 出处与实现口径宜对齐（采古法或明示「并陈醉醒子法」）。

## 3. C 类问题（口径/精度，宜注明）

- **C3 节气近似回退：** 1950–2050 之外用内置近似（误差 < 1 天），已在代码注明。

### A6 「天元作禄」张冠李戴（中）

**代码（`hitNamedPatterns`，修订前）：**
```java
if ("临官".equals(stageOf(dayGan, dayZhi))) {          // 日支为日干之禄（日坐禄）
    hits.add(new String[]{"天元作禄", "日干自坐禄旺、官星得用之格", "三命通会卷五·天元作禄"});
}
```
即：凡「日支＝日干临官」者（甲寅、丙午、戊午、庚申、壬子…）即判「天元作禄」。

**原著：** 三命通会卷五·○天元作禄：
> 「经云：金若遇火，有重权……（如**庚午、庚寅、庚戌、辛巳、辛未**等日）。水若遇土，入官局……（如壬午、壬戌、癸巳……）。木若遇金……（如甲申、甲戌、乙巳……）……此即白虎持世等格要，**日主与官贵相亭**……**日主自作官星**，不大忌冲，譬执物在手……古歌曰：**座下官星**最是奇，多因祖荫见根基。」（三命通会.txt:7578–7596）

即**「天元作禄」＝日干（天元）自坐官星（座下官星）**，非「日坐禄」。现码以「日支临官」判，与原著**名实不符**：其一，把「日坐禄」日（甲寅、庚申…）误标为「天元作禄」；其二，原著所举之「日坐官星」日（庚午、辛巳…）反**不被识别**。以庚午日（庚坐午，午藏丁＝庚之正官）回代现码：`stageOf(庚,午)=沐浴`，**不判命中**——与原著例直接相违。

**判定：** 错误（张冠李戴）。应改为「日支藏干中有日干之官星（正官/偏官）」方判。
