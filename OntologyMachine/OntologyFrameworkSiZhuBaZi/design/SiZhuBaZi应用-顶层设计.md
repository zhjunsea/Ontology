## 1. 概述与定位

`OntologyFrameworkSiZhuBaZi`（应用简称 **SiZhuBaZi**）是本工程中的一个**本体应用模块**，用于将以**日主（日干）为中心**的四柱命理（子平法）推命过程建模为可执行的本体应用。

**业务定位**：用户输入**命主的出生时间信息**（出生年、月、日、时，公历或农历，性别，必要时含出生地以校正真太阳时），应用按四柱命理「**排盘 → 定十神 → 判格局取用 → 推岁运**」的主干流程，推断命主的**命局层次、性情禀赋与人生走势**——即回答：

1. **命局强弱与格局高低如何？**（日主旺衰 + 成格破格 → 层次判据）
2. **用神喜忌为何？**（用神/相神/忌神 → 取用得失）
3. **大运流年吉凶、应于何事？**（岁运干支与原局关系 → 岁运断）
4. **六亲、婚姻、事业、财运、疾病等分类事项如何？**（十神/宫位/神煞 → 分类断）

> 出处：《渊海子平》卷之一「论日为主」「论月令」确立以日干为主、以月令为提纲；《子平真诠》「论用神」「论行运」；《滴天髓》「体用」「衰旺」「中和」。

它与 `OntologyFrameworkExample`（Example）、`OntologyFrameworkPlumBlossom`（梅花易数）等是**同工程内并列、独立**的应用模块，共享底层的 `OpenlletResolver`、`OntopOBDAHandler` 与 `Utilities` 三个能力模块。

**核心特征：**

- **本体即约束**：干支五行、十神、格局、用神、大运等业务约束由 OWL TBox 表达，Openllet 推理器在运行时判定，非硬编码。
- **BPMN 管编排**：「排盘 → 十神 → 格局取用 → 岁运 → 综合断」流程拓扑定义在 BPMN 中，部署到 Camunda 8 / Zeebe 由引擎驱动。
- **Ontop 虚拟取数**：历法/节气数据（干支、藏干、纳音、神煞查表等）留在 MySQL，经 Ontop OBDA 映射以 SPARQL 视角读写。
- **前端可交互**：Web 页面提供生辰信息录入，启动流程并轮询显示排盘与批断结果。
- **消息外发**：重大判定（大凶、寿元关、重大疾病提示等）经 SWRL 推理自动触发 RabbitMQ 消息外发。

## 5. 关键设计决策

1. **以日主为中心的子平格局体系为主干**：主干流程「排盘 → 十神 → 格局取用 → 岁运 → 综合断」，与四书主线一致（渊海子平「论日为主」、子平真诠「论用神」）。四书内容尽纳入（含神煞、纳音、六亲、女命、气势中和）。
2. **本体即约束、计算外置**：干支/十神/格局/用神等**分类与约束**由 OWL TBox + SWRL 承载；**历法换算、节气计算、真太阳时校正等数值计算**外置到 Java/BPMN（★铁律 13）。
3. **数据外置**：藏干、纳音、神煞起例、五行旺衰等**查表型数据**迁入本体/数据库，程序不硬编码业务数据（★铁律 14）。
4. **流派差异如实呈现**：四书对同类事项的差异口径（如格局取舍）在设计中登记来源与分歧，不臆造唯一断语（★铁律 9/10）。
5. **复用工程既有能力**：前端→BPMN→JobWorker→Openllet→Ontop→RabbitMQ 全链路沿用 Example/PlumBlossom 同构形态；复用现存 API（★铁律 21）。
