## 一、看行业 / 趋势　`节点: scan-industry-trend · jobType: scan-industry-trend`

### 🔎 检索采集（关键事实与来源）
- **国内装机**：截至 2025 年底，全国风电累计装机 **6.4 亿千瓦**，同比 **+22.9%**，连续 15 年世界第一；2025 年新增 **1.2 亿千瓦**（同比 +51%，其中陆上 1.1 亿千瓦、海上约 659 万千瓦）。〔S2、S6〕
- **结构转折**：2025 年风电+光伏累计并网 **18.4 亿千瓦**，占全国电力总装机 **47.3%**，**历史性首次超过火电**；风光发电量合计 2.3 万亿千瓦时（+25%），占全社会用电量约 22%。〔S1、S2〕
- **投资力**："十四五"全国主要电力企业电源工程投资累计 **46580 亿元**（较"十三五"+163.6%），其中**风电太阳能占电源总投资 62.5%**。〔S1〕
- **全球市场**：2025 年全球风电新增装机首破 **150 GW**；预计 **2030 年全球累计突破 2 TW**。〔S5〕
- **政策主线**：2026 年为"十五五"开局之年，《可再生能源发展"十五五"规划》提出到 2030 年可再生能源发电总装机约 35 亿千瓦、**风电和太阳能总装机 28 亿千瓦以上**，**海上风电累计并网 1 亿千瓦以上**；"十五五"期间风电年新增不低于 **1.2 亿千瓦**，其中海上年新增不低于 **1500 万千瓦**。《风能北京宣言 2.0》同调。〔S2、S4〕
- **技术趋势**：单机容量持续突破（陆上平均已达 4.2 MW、海上超 7.4 MW；中国已进入 20 MW 级）；**数字孪生、人工智能、物联网、5G、云**被视为核心使能技术；行业正从"规模化建设期"转入"**精细化运营期**"。〔S2、S15、S20〕
- **后服务市场**：全球风电后服务市场预计 2030 年产值达 **280 亿美元**（约 2000 亿元人民币），**亚太占 41%**。〔S19〕

### 🧮 加工分析
1. **量的积累已成、质的需求方起**：装机规模高位（6.4 亿千瓦、年新增 1.2 亿千瓦）为 IT/数字化提供了庞大"存量资产 + 年增量"的数据与运维对象；政策从"拼装机"转向"**消纳、协同、提质增效**"，正是数字化价值的落点。〔S1、S2、S25〕
2. **从建设期到运营期 = IT 需求结构迁移**：当资产从"跑马圈地"转入"存量运营"，需求由一次性工程 IT 转向**持续运营型数字化**（智能运维、预测性维护、集控、交易辅助）。〔S11〕
3. **后服务降本直接靠数字化**：后服务成本集中在定期检修、大修与备件，数字化（数字孪生+数据挖掘）可把"定期检修"改为"预测性维护"，是可量化的付费点。〔S19〕
4. **趋势判断**：行业 IT 空间处于"**政策强驱动 + 存量运营刚需 + 技术成熟度足够**"三重共振窗口。

### ✅ 节点结论
风电产业已跨过"规模驱动"拐点，**数字化/IT 投入的核心驱动力从"新建工程"转向"存量资产运营提质 + 政策合规"**；IT 空间随"十五五"高装机（年≥1.2 亿千瓦）与后服务数字化（2000 亿元级）持续放大。

## 二、看市场 / 客户　`节点: scan-market-customer · jobType: scan-market-customer`

### 🔎 检索采集
- **客户高度集中**：下游为**国家电网、南方电网及五大发电集团**等，需求稳定性强；2023 年风电有新增装机的开发企业 200 余家，**前 15 家占新增装机 73.1%**，下游呈"电力巨头垄断"。〔S13、S19〕
- **典型业主侧建设**：超 90% 能源电力央企成立数字化牵头部门；三峡集团成立专职部门，诊断覆盖集团总部及 **17 家下属单位**；央企累计成立**数科公司 116 家**。〔S22〕
- **客户痛点**：① 数据孤岛——多家主机/部件厂商设备数据格式不一、接口封闭，阻碍全场级、跨品牌协同；② 设备维护成本高、并网协调效率低、弃风；③ **海上风电后期运维成本占总成本一半以上**；④ 中小投资商数字化"投入大、周期长、见效不确定"。〔S24、S27、S19〕
- **需求场景（发电侧数字化）**：智能运维（天气/发电量预测、智能巡检、预测性维护）、**产业中台（集控中心）**、功率/电价预测与交易辅助、数据治理与安全合规。〔S11、S26〕
- **供给侧缺口（面向中小微）**：电力领域中小微企业**缺少面向用能侧的 SaaS 应用**，传统专有云建设成本高、周期长。〔S26〕

### 🧮 加工分析
1. **客户结构 = 头部大 B 主导**：核心 IT 项目倾向选择**具备国资背景/资质**的服务商，民营多在细分赛道分包；大 B 客户对资质、项目经验、服务能力要求极高，构成**天然进入壁垒**。〔S13、S14〕
2. **痛点即产品议程**：数据孤岛→**数据治理/一体化平台**；运维成本高→**智能运维/数字孪生**；协同低效→**集控/产业中台**；安全合规→**电力监控安全防护/等保**。
3. **一个被低估的增量**：面向中小微能源企业的**轻量化 SaaS/云服务**供给不足，是差异化切入空白。〔S26〕
4. **采购逻辑**：国企倾向自主运维，供应商须以**技术优势与服务能力**提升委托意愿。〔S19〕

### ✅ 节点结论
客户主体是**集中度极高的能源电力央企/国企**，付费能力与政策执行力强；需求已从"上系统"升级为"**数据打通 + 智能运营 + 安全合规 + 集控协同**"的系统性诉求。进入策略须匹配大 B 的资质与交付要求，并可捕捉**中小微 SaaS 空白**。

## 三、看竞争　`节点: scan-competition · jobType: scan-competition`

### 🔎 检索采集
- **电力信息化竞争格局**：呈"**国资主导、民营补充**"分层结构；**CR5 已超五成**，行业份额持续向头部集中；头部国资龙头（国网信通）2024 年营收规模约为民营细分龙头的 **7 倍以上**，业务覆盖云网基础设施、电力数字化服务、企业数字化转型三大板块。〔S13、S14〕
- **细分玩家**：配网自动化以国电南瑞、许继电气、东方电子等"电网系"主导，细分赛道（通信模块、传感芯片、故障定位算法）有"专精特新"民企突围；电力信息化民企（泽宇智能、理工能科等）聚焦配用电/调度细分。〔S14〕
- **风电数字化/数字孪生厂商**：风电数字孪生（CIMPro 孪大师、飞渡科技、51WORLD、数字冰雹、易知微、山海鲸）；智慧风电软件（华为、必可测、DataFocus、深信服、阿里云、运达股份、北京云智软通、镭…）。〔S15、S16〕
- **科技巨头打法**：以云计算/大数据/AI 大模型/物联网为底座，定位"**技术赋能、平台输出、生态合作**"，短板在**行业场景深耕不足、交易运营经验薄弱、线下落地能力偏弱**。〔S17〕
- **整机厂入局**：金风科技、运达股份、明阳智能、三一重能等整机厂正加速"双海"与数字化布局，O&M 环节整机厂逐渐入局。〔S7、S8、S19〕

### 🧮 加工分析
1. **格局分层**：① 电网/发电集团系"国家队"（拿总包大单）；② 细分"专精特新"民企（抢算法/部件缝隙）；③ 跨行业科技巨头（提供云/算法底座、生态赋能）；④ 风电整机厂（由设备向运维/数字化延伸）。**四类主体在同一 IT 空间交汇。**
2. **竞争焦点迁移**：从"单一设备/软件供应"转向"**解决方案 + 全生命周期服务**"，以及"**算法精细化 + 场景深耕 + 交易运营 + 资质生态**"的综合壁垒。〔S14、S17〕
3. **科技巨头的现实短板**：通用能力强、行业纵深弱——在风电这类"**重场景、重交易、重线下交付**"的领域难以独立完成全流程运营，多以技术服务商角色参与分工。〔S17〕
4. **数字孪生赛道结论（样本对比）**：厂商在渲染、风电场景适配、信创全栈、开发门槛、成本、IoT 协议覆盖上分化明显；**多数厂商风电非主战场**（如飞渡主攻水利/CIM），风电专项模板与设备级精密仿真普遍薄弱。〔S15〕

### ✅ 节点结论
IT 空间竞争"**头部国资主导 + 垂直专精 + 科技巨头赋能 + 整机厂延伸**"并存；**通用型平台正被场景深耕型方案挤出**。制胜要件是"场景深耕 + 算法壁垒 + 全流程交付 + 资质/生态"，单纯技术或价格竞争难持久。

### 🔎 检索采集

- 科技巨头的**短板**：**行业场景深耕不足、交易运营经验薄弱、线下落地能力偏弱**，难独立完成全流程商业运营。〔S17〕
- 行业**共性人才/能力缺口**：数字化转型面临**数据壁垒、网络安全、数字化人才缺失**；部分企业"把数字化等同于信息化"，业务架构优化不足。〔S24、S22〕

### 🧮 加工分析
- 若自身定位为**云/IT 底座型服务商**：长板=算力/平台/算法/安全底座；短板=行业 Know-how 与线下交付 → 应"**以生态合作补场景短板**"。
- 若定位为**行业解决方案商**：需补齐**数据治理、电力监控安全（等保/二次安防）、交易辅助**等专业能力。
- **通用短板清单**：【待考，须主体自评】① 电力行业资质与准入；② 场景数据积累与垂类模型；③ O&M 线下服务网络；④ 数据安全合规体系。

### ✅ 节点结论
自身能力的核心矛盾是"**技术底座强 vs 行业纵深弱**"。无论何种定位，**"补齐行业场景与交付能力"是进入风电 IT 空间的先决条件**——应优先走**生态协同**（与整机厂/国资方案商/标准组织合作）而非单打独斗。（具体自评待业务方代入，**【待考】**）

## 五、看机会　`节点: scan-opportunity · jobType: scan-opportunity`

### 🔎 检索采集
- **增量装机机会**：十五五风电年新增≥1.2 亿千瓦；海上风电从 2025 年底 **0.47 亿千瓦** → 2030 年 **1 亿千瓦以上**（五年翻番有余）。〔S2、S4〕
- **"以大代小"改造**：早期 1.5 MW 及以下老旧机组面临技改，**存量改造成为"第二增长曲线"**。〔S2、S25〕
- **新形态**：分散式风电/"千乡万村驭风行动"、**绿电直连**、风光大基地（沙戈荒）、**非电利用（绿氢氨醇）**——国内已启动绿色甲醇项目超 2800 万吨，到 2030 年可带动 **100 GW 以上风电消纳**空间。〔S7、S25〕
- **海风×算力新图景**：将海上风电与 **AIDC（算力中心）** 结合，就近消纳海上绿电、减海缆依赖。〔S3〕
- **IT/数字化市场**：2025 年中国电力智能化市场规模约 **1220.2 亿元**（同比 +8.1%）；〔提示：该口径来源为行业媒体，**建议以权威机构口径复核**〕〔腾讯云开发者社区〕；能源领域信息化/IT 应用有专门的年度投资研究（硬件/软件/服务分项）。〔S18〕
- **数字化价值已被案例量化**（埃森哲×远景）：无人监控与巡检可**降巡检成本 25%–30%、降维护成本 20%–30%、降事故率 70%–90%**；特变电工光伏电站案例：**降运营成本 15.26%、发电量提升 5.39%**；大唐先一集中控制系统**降成本 50%+**。〔S11、S23、S22〕

### 🧮 加工分析
1. **机会矩阵（按确定性排序）**：
   - 高确定：**智能运维/预测性维护、集控/一体化管控平台、数据治理与安全合规**（存量刚需、政策强制）。
   - 中确定：**数字孪生、功率/电价预测与交易辅助**（技术成熟、付费模式待验证）。
   - 高增长：**海上风电运维数字化、绿电直连/非电利用协同平台、海风×算力**（政策与产业双驱动，**增速高但成熟度低**）。
2. **价值可量化**：数字化收益已有"降本 X% / 增发 Y%"的实证，利于商业闭环论证。
3. **空白点**：面向中小微能源企业的**轻量化 SaaS/云服务**；跨品牌**数据互通/标准**（数据孤岛治理）。〔S26、S24〕

### ✅ 节点结论
风电 IT 空间的**最大机会 = "存量运维数字化的确定性刚需" + "海上/非电等新形态的高增长期权" + "中小微 SaaS 与数据互通的标准空白"**。建议以确定性刚需做现金流、以新形态做增长、以标准/数据治理做壁垒。

## 六、定战略控制点　`节点: define-control-point · jobType: define-control-point`

### 🔎 检索采集（控制点依据）
- **数据**：SCADA、CMS、智能传感器、多源异构（结构化/非结构化/时序/文本）数据融合是智能化的基础；老机组数据缺失、协议封闭形成"数据孤岛"。〔S21、S22、S24〕
- **算法**：虚拟电厂分析指出**算法能力是核心竞争力与"不可复制的技术壁垒"**（自研垂类大模型、多目标优化调度）。〔S17〕
- **平台/架构**：行业标准确立**"云边端协同 + 一体化管控平台 + 智能应用组件即插即用"**架构方向（NB/T 11357-2023）；AI 风电监控要求**分层分布式 + 云边协同 + 可解释/可追溯**。〔S21、S22〕
- **标准/信创**：风电机组数字孪生（T/CES 214-2023）、智能风电场一体化管控平台（NB/T 11357-2023）等标准已发布；数字孪生厂商把**信创全栈（龙芯/鲲鹏/飞腾+麒麟/UOS+达梦/金仓）**作为关键竞争维度。〔S20、S21、S15〕
- **安全合规**：须满足电力监控安全防护（GB/T 36572）、等保（GB/T 22239）等强制要求。〔S21〕

### 🧮 加工分析
提炼可构筑"护城河"的控制点：
1. **数据控制点**：掌握**多源异构数据的采集-治理-融合**能力与标准（破解数据孤岛）——越跨品牌越有价值。
2. **算法控制点**：面向风电场景的**垂类模型/预测性维护/功率与电价预测**算法库（可迁移、可持续迭代）。
3. **平台控制点**：**云边协同 + 一体化管控平台 + 组件化生态**（即插即用，锁定开发者与集成商）。
4. **标准/信创控制点**：参与**标准制定** + **全栈信创兼容**（政府采购硬门槛）。
5. **安全合规控制点**：**电力二次安防/等保三级**等资质能力（准入门槛）。
6. **生态控制点**：产业链协同（海上风电产业链联盟式联合研发/标准共制）。〔S4〕

### ✅ 节点结论
建议以"**数据 + 算法 + 平台**"为**技术控制点核心**，以"**标准/信创 + 安全合规**"为**准入门槛型控制点**，以"**生态协同**"为**放大器**。其中**跨品牌数据治理能力**与**场景垂类算法**最符合"难复制、可持续"的控制点特征。

### 🔎 检索采集（目标设定基准）
- 行业增速基准：2026 年全国风电新增装机预计约 **1.2–1.3 亿千瓦**，累计接近 7 亿千瓦；2030 年累计有望破 12 亿千瓦。〔S2、S6〕

## 八、定策略　`节点: define-strategy · jobType: define-strategy`

### 🔎 检索采集（策略依据）
- **央企转型建议**：增强战略协同并动态优化、机制创新支撑数字人才/文化、**试点示范引领**、**技术协同打造开放创新合作空间**。〔S22〕
- **平台化路径**：从"数字化底座"到"智慧云脑"，走**实时采集→智能清洗→深度分析**的贯通路线；电力企业普遍仍处"数据资源化"初级阶段。〔S26〕
- **商业模式**：可"平台+服务"（平台服务费、增值服务费、定制开发费；软件授权/项目总包/订阅）。〔S23、S18〕
- **生态协同**：海上风电产业链联盟以**联合研发、标准共制、供需对接**破解共性挑战，行业从"单点竞争"转向"协同创新"。〔S4〕
- **数据安全策略**：建立权责明晰的数据安全管理组织体系、分类分级、应急响应机制。〔S22〕

### 🧮 加工分析（策略框架）
1. **进入策略**：优先切入**高确定性刚需**（智能运维、集控平台、数据治理），用试点示范建立标杆，再横向复制。〔S22〕
2. **差异化策略**：以**场景深耕 + 垂类算法 + 跨品牌数据互通**对抗"通用型平台同质化"；用**信创全栈 + 安全合规**跨过准入硬门槛。〔S15、S17、S21〕
3. **合作策略**：与**整机厂、国资方案商、标准组织**生态协同，补"线下交付/行业资质/交易运营"短板；加入/共建产业链联盟。〔S4、S17〕
4. **交付策略**：面向大 B 走"**解决方案 + 全生命周期服务**"；面向中小微走"**轻量化 SaaS/云服务 + 平台+服务**"模式。〔S14、S26〕
5. **区域策略**："一地一策"——东部求极致可靠性、中西部解决高渗透率消纳、农村补网架短板（对方案商意味着差异化产品线）。〔S16〕
6. **风控策略**：把**数据分类分级、等保三级、二次安防**内建为产品能力而非附加项。〔S21、S22〕

### ✅ 节点结论
总体策略：**"刚需切入（智能运维/集控/数据治理）→ 标杆复制 → 场景深耕差异化 → 生态协同补短板 → 平台+服务变现"**，并以"**信创 + 安全合规**"为通行证、"**跨品牌数据互通 + 垂类算法**"为长期壁垒。

## 九、总结与建议

1. **市场判断**：风电 IT 空间处于"政策强驱动（十五五高装机）+ 存量运营刚需 + 技术成熟"三重共振窗口，市场量级（电力智能化 1220 亿元级）随装机与后服务数字化持续放大。（口径待复核）
2. **需求判断**：客户为高度集中的能源电力央企/国企，诉求由"上系统"升级为"**数据打通 + 智能运营 + 集控协同 + 安全合规**"。
3. **竞争判断**：**头部国资主导 + 垂直专精 + 科技巨头赋能 + 整机厂延伸**；通用平台被场景深耕挤出。
4. **机会判断**：确定性机会=存量运维数字化；高增长期权=海上风电/非电利用/海风×算力；空白=中小微 SaaS 与跨品牌数据标准。
5. **战略建议**：控制点押注"数据 + 算法 + 平台"，准入押注"标准/信创 + 安全合规"，打法押注"生态协同 + 平台即服务"。
6. **风险提示**：① 政策与补贴变动（陆上增值税即征即退已取消）；② 数据安全与合规风险；③ 同质化价格战；④ 数字人才短缺；⑤ 【待考】自身主体基线与资源约束未定。
