## 四、SKOS 词表

`tcm-zhengzhuang_skos.ttl`：**747 个 `skos:Concept`**（≈ 430 KB；另含 1 个 `skos:ConceptScheme`）；全部 747 条与四诊 ABox 个体一一对应。

| 通道 | 概念数 |
|---|---|
| 症状 | 598 |
| 脉象 | 69 |
| 舌象 | 76 |
| 腹证 | 4 |
| **合计** | **747** |

- 与 ABox 个体**一一对应**（`skos:prefLabel` = ABox 个体 `rdfs:label`，共 747 条；词表 `skos:Concept` 总数 747，另含 1 个 `skos:ConceptScheme`）。
- 同义词总量 **1231 条**（`skos:altLabel` 250 + `skos:hiddenLabel` 981，按**标签值**计数；
  与应用日志 `SymptomCatalog`「1231 条口语同义词」一致）。注意：`skos:altLabel` / `skos:hiddenLabel`
  以**逗号分隔多值**书写，故「谓词出现次数」（213 / 577）≠「标签值个数」（250 / 981）。
- `subClassOf` / `equivalentClass` 均为 **0 条**，对六经推理**零贡献**。
- 是「口语/文言/缩写 → 本体规范名」映射的**唯一权威来源**（铁律 61）。

## 五、计数口径说明（重要）

本工程存在两种「类数」口径，文档引用时须注明：

| 口径 | 定义 | 典型值 |
|---|---|---|
| **顶层具名类** | `rdf:RDF` 直接子元素、且带 `rdf:about` 的 `owl:Class` | core 83 / zhengzhuang 595 / maixiang 68 / shexiang 78 / yaozheng 52 / fuzheng 4 / huchi 32 |
| **`<owl:Class` 原始出现数** | 文件内 `<owl:Class` 字符串出现次数（含嵌套匿名类与引用） | core 174 / maixiang 185 / shexiang 102 / yaozheng 164 |

> 早期文档中「脉象 185 类 / 舌象 102 类 / 药证 164 类」用的是**原始出现数**口径；
> 若按顶层具名类计则为 **68 / 78 / 52**。两者不矛盾，但**不可混用**（铁律 20/21）。
