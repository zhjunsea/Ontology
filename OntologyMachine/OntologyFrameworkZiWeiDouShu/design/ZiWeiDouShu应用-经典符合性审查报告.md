## 1. A 类问题（与原著相违 / 明确错误）

### A1 庙旺利陷以「五行生克近似」代替《全書》庙陷表（高）

**原实现（节点 7 `assessBrightness`，审查前）：** 以自拟的「星曜五行生克（宫位五行 vs 星曜五行）」程序规则**近似**推出庙/旺/陷，并把出处标注为「卷三·诸星庙陷」。

**原著：** 《全書》庙陷是**成表的固定等第**，载于 **卷二·星辰庙陷**（以「十二支 × 庙/旺/得地/利益/平和/不得地/落陷」七等网格给出，`c1_..._quan_lan.txt` L1039–1088）；另 **卷二·定十二宫星辰落闲**（`c3` L132）单列「闲宫」。庙陷**不是**生克可推导的量，属**查表型**（与 DB `brightness_map` 240 行同源）。

**判定：** 错误（口径错误）。应以**成表查取**取代生克近似。**处理：** 在 JobWorker 内置 21 星 × 12 宫 `BRIGHTNESS` 表（与 `brightness_map` / `gen_zwds_db_full.py` 的 `BRIGHT` 同源），新增 `brightnessOf(star,branch)` 查表（表内缺项＝结构上不可入之宫，运行时以「平和」兜底）；节点 7 改为逐星**查表定等第**；出处校正为卷二·星辰庙陷。经与网格**逐星逐宫比对一致**（抽样：子/辰/亥三宫全对，见 §4）。

### A2 星辰落闲（卷二元诀）未实现（中）

**原著：** 卷二·定十二宫星辰落闲：「紫微在子辰亥为闲宫，贪狼在寅辰为闲宫，天相在辰戌为闲宫，七杀在辰亥为闲宫，天梁在巳酉为闲宫，天机在巳为闲宫，破军在巳申为闲宫，武曲在申为闲宫。」（`c3` L132–134）

**判定：** 缺失（原著有诀而未落地）。**处理：** 新增 `IDLE_STAR` 表 + `isIdleStar()`，节点 7 逐星判落闲，新增结果键 `idleStars`。

### A3 DB 四化表「壬化科」用通行异说，与《全書》及 Java 内置表矛盾（中高）

**原文（卷二·安禄权科忌四星变化诀，`c3` L59–62）：**
> 「…壬梁紫府武宿是，癸破巨阴贪狼停。」→ 壬干：**天梁化禄、紫微化权、天府化科、武曲化忌**。

**问题：** `ontology/database/data.sql` 的 `sihua_map` 中 `SH_Ren_Ke` 记 **`ZuoFu`（左辅）**、`source_note` 误引「卷一·諸星問答論·四化」（该书卷一并无此干→星表）；而 Java 内置 `SIHUA[壬]`＝`{天梁,紫微,天府,武曲}`（＝卷二诀）。二者**对同一命盘给出不同四化**——经 OBDA（查库）与离线（内置兜底）两路结果不一致。生成器 `gen_zwds_db_full.py` L204 亦作 `ZuoFu`。

> 注：现代通行流派确有「壬左辅化科」之说，但（a）本项目权威＝《全書》，其卷二诀明作「府」；（b）Java 侧亦作「府」；（c）DB 自身引据（卷一）不存在该表。故应统一为「天府」，并把「左辅化科」作为**异说备注**留存。

**判定：** 错误（与原著及内部实现相违）。**处理：** DB `sihua_map` 壬化科 `ZuoFu`→`TianFu`、`source_note` 改为「卷二·安禄权科忌四星变化诀【壬化科「左辅化科」异说·待考】」；生成器 `gen_zwds_db_full.py` 同步（`ZuoFu`→`TianFu` + 壬专属 note）；Java `SIHUA` 补异说备注。修正后 DB `sihua_map` 40/40 与 Java 表逐条一致。

### B3 格局判定不全集（中高）

### 34.3 关键修正说明（缺陷 2 处）

1. **七杀重逢（永假缺陷）**：原判据 `countStar(at, "七杀") >= 2`——七杀为单颗主星、全盘仅布一宫，`countStar` 恒为 1，故「七杀重逢」**永远不触发**，属「已声明却永不落地」。修正为 `judgeQiShaReFeng(mingIdx, at, flowGan)`：本命七杀落命宫三方四正（含对宫）**且** 流年流羊/流陀落七杀宫或其对宫 → 重逢。符合原文「命中三合原有七杀守照，而流年又遇流羊流陀冲照凶」。
