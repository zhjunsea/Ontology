推演原理：卦象如何推导 · 吉凶如何定数

一、卦象推导过程（起卦 → 成卦 → 定体用 → 察互卦 → 观变卦）

1. 起卦定数：依所选起卦法取得「上卦数、下卦数、动爻源」。先天（未得卦先得数、以数起卦）如年月日时、物占数、字占等；后天（未得数先得卦、以象起卦）如物卦起例、风觉占、验色占等。

2. 成卦（本卦）：卦数起例——卦以八除，余数作卦，余 0 作 8（坤）；先天卦数 乾1、兑2、离3、震4、巽5、坎6、艮7、坤8。上卦下卦相重即为本卦（六十四卦名录依六十四卦次第歌）。（卷之一·卦数起例）

3. 定动爻：爻以六除——重卦总数除六，余数作动爻，余 0 作 6；一卦一爻动。（卷之一·爻以六除）

4. 定体用：动者为用、静者为体——动爻所在之卦为用卦，另一卦为体卦（动爻在初/二/三爻→下卦为用、上卦为体；在四/五/上爻→上卦为用、下卦为体）。体卦为主＝己身之兆，用卦为事＝应事之端。（卷之三·断占总诀；卷之二·体用总诀）

5. 察互卦：去了初爻及第六爻，以中间四爻分作两卦——2/3/4 爻为互卦下卦、3/4/5 爻为互卦上卦；互卦为事之中间。特例：乾坤无互，互其变卦。（卷之一·互卦止用八卦；卷之三·体用互变之诀）

6. 观变卦：一爻动，阳爻变阴爻、阴爻变阳爻，余五爻不变；变卦为事之终、最终趋向。（卷之一·爻以六除；卷之二·体用总诀）

二、吉凶如何定数（生克 → 旺衰 → 类象 → 分类 → 外应 → 断吉凶 → 应期）

1. 五行生克：乾兑金、坤艮土、震巽木、坎水、离火；金生水→水生木→木生火→火生土→土生金，金克木→木克土→土克水→水克火→火克金。体用五级：用生体＝最吉（进益之喜）＞体用比和＝次吉（百事顺遂）＞体克用＝小吉＞体生用＝有耗（耗失之患）＞用克体＝最凶。同时查互卦、变卦与体卦的生克。 （卷之一·八宫所属五行 / 五行生克；卷之二·体用总诀）

2. 卦气旺衰：震巽木旺于春、离火旺于夏、乾兑金旺于秋、坎水旺于冬、坤艮土旺于辰戌丑未月。总原则：体卦宜乘旺、克体之卦宜衰。（卷之一·卦气旺衰；卷之二·衰旺论）

3. 万物类象：紧扣所问之事、呼应体用生克、优先取动象与应象。（卷之一·八卦万物属类 / 八卦万物类占）

4. 分类占断：以体为主、用为所应，依原著卷之二十八章占例分项立断，类别可「以类而推」。

5. 参外应：有三要十应则与卦互参，但以易卦为主、克应次之，外应不覆盖体用主判。（卷之二·三要灵应篇 / 十应目论；卷之二·占卜总诀）

6. 断吉凶·以理统数：成卦之后先看《周易》爻辞以断吉凶 → 次看卦之体用论五行生克 → 又次看克应 → 复验己身之动静；生体多者则愈吉，克体多者则愈凶；俱吉则大吉、俱凶则大凶；数有不验，必以理论之而后备。（卷之二·占卜总诀 / 占卜论理诀 / 体用总诀）

7. 定应期：克应即刻期——远者以全卦之数为年期、近者为月期、又近者为日期；以生体及比和之年月为吉期、克体之年月为不吉之期；坐则事应迟、行则事应速、走则愈速、卧则愈迟。（卷之三·克应；卷之二·占卜总诀）
