## 一、设计原则（三条核心修正）

| 编号 | 原则 | 说明 |
| :--- | :--- | :--- |
| **①** | **不把“方证”做死** | 方证 = 核心病机（必要条件）+ 或然症（加权项）。不用 `EquivalentTo` 硬绑定。方剂 `treats` 病机，SWRL动态判定。 |
| **②** | **合病与兼夹彻底分叉** | 合病 = 两经同病 → **合方**（1+1）。兼夹 = 病理产物 → **加药**（1+0.1）。BPMN Step 4 必须分两条路径。 |
| **③** | **SWRL 分层裁决** | 不搞死板“一票否决”。分三层：硬性否决（红线）→ 特异性加减（活路）→ 优先级裁决（表里先后）。 |

## 四、LOGIC 层：SWRL 规则分层设计

### 4.1 第一层：硬性否决规则（红线）

| 规则 | 触发条件 | 结果 | 条文依据 |
| :--- | :--- | :--- | :--- |
| 桂枝汤否决 | 患者匹配“营卫不和”病机 + 存在“无汗”或“脉紧” | 否决桂枝汤 → 转向麻黄汤匹配 | 第35条 |
| 小青龙汤否决 | 患者匹配“表寒里饮”病机 + 存在“脉弱”或“汗出” | 否决小青龙汤（防亡阳） | 胡老“脉弱汗出，不可峻汗” |

### 4.2 第二层：特异性加减规则（活路）

| 规则 | 触发条件 | 结果 | 条文依据 |
| :--- | :--- | :--- | :--- |
| 桂枝加葛根汤 | 匹配“营卫不和”病机 + 存在“项背强几几” | 桂枝汤 + 葛根 → 桂枝加葛根汤 | 第14条 |
| 小柴胡加减（渴） | 匹配“少阳枢机不利”病机 + 存在“渴” | 小柴胡汤 - 半夏 + 人参 + 瓜蒌根 | 第96条 |

### 4.3 第三层：优先级裁决规则（表里先后）

| 规则 | 触发条件 | 结果 | 条文依据 |
| :--- | :--- | :--- | :--- |
| 里急先救里 | 同时存在表证+里证 + 里证危急（谵语/潮热/腹满痛） | 治疗策略 = “先治里（急下之）” | 第372条 |
| 表里俱实先解表 | 同时存在表证+里证 + 里证未危急（仅便秘/微热） | 治疗策略 = “先解表，后攻里” | 第106条 |
