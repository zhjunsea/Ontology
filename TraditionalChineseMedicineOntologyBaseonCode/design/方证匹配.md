# 第四步：方证对应匹配 —— 严格逻辑重构

## 一、核心原则重申

基于你提供的本体结构与BPMN流程，第四步的逻辑必须是：

> **方证的必见主症（`has_symptom`）必须是患者症状的子集。缺一条即排除，不打分、不排序、不凑合。**

`has_or_symptom`（或然症）**不参与**必要性校验。`has_concomitant`（兼夹）作为**兼容性过滤器**而非加分项。

## 二、完整Java代码（Zeebe Worker）

```java
package com.tcm.jingfang.worker;

import io.camunda.zeebe.client.api.response.ActivatedJob;
import io.camunda.zeebe.client.api.worker.JobClient;
import io.camunda.zeebe.spring.client.annotation.JobWorker;
import org.semanticweb.owlapi.model.*;
import org.semanticweb.owlapi.reasoner.NodeSet;
import org.semanticweb.owlapi.reasoner.OWLReasoner;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.stereotype.Component;

import java.util.*;
import java.util.stream.Collectors;

/**
 * 第四步：方证对应匹配（严格逻辑，无权重）
 * 
 * 核心逻辑：
 *   FangZheng_X ⟺ (S_key ⊆ S_patient) ∧ (C_channel ∋ C_patient) ∧ Concomitant_Compatible
 * 
 * 禁止：评分、排序、Jaccard、概率推断。
 * 有是证用是方，无证则不用。
 */
@Component
public class Step4FangZhengMatchWorker {

    private static final Logger log = LoggerFactory.getLogger(Step4FangZhengMatchWorker.class);

    // ==================== 命名空间常量 ====================
    private static final String TCM_NS    = "http://www.tcm-classics.org/tcm#";
    private static final String BZ_NS     = "http://www.tcm-classics.org/bingzheng#";
    private static final String ZZ_NS     = "http://www.tcm-classics.org/zhengzhuangtizheng#";
    private static final String MX_NS     = "http://www.tcm-classics.org/maixiang#";
    private static final String SX_NS     = "http://www.tcm-classics.org/shexiang#";
    private static final String LJ_NS     = "http://www.tcm-classics.org/liujing#";
    private static final String BG_NS     = "http://www.tcm-classics.org/bagang#";
    private static final String JJ_NS     = "http://www.tcm-classics.org/jianjia#";
    private static final String FJ_NS     = "http://www.tcm-classics.org/fangji#";

    private final BackendService backendService;

    public Step4FangZhengMatchWorker(BackendService backendService) {
        this.backendService = backendService;
    }

    // ==================================================================
    // Zeebe Worker 入口
    // ==================================================================
    @JobWorker(type = "step4-fangzheng-match", autoComplete = false)
    public void handleStep4FangZhengMatch(final ActivatedJob job, final JobClient client) {
        try {
            // ---- 1. 读取输入变量（由BPMN ioMapping传入）----
            Map<String, Object> vars = job.getVariablesAsMap();
            String sixChannel = (String) vars.get("sixChannel");
            @SuppressWarnings("unchecked")
            List<String> symptomIris = (List<String>) vars.get("symptomIris");
            @SuppressWarnings("unchecked")
            List<String> concomitantPathologies = (List<String>) vars.get("concomitantPathologies");
            String clinicalCaseIri = (String) vars.get("clinicalCaseIri");

            log.info("▶ step4 开始 | 六经={} | 症状数={} | 兼夹={}",
                    sixChannel, symptomIris != null ? symptomIris.size() : 0,
                    concomitantPathologies);

            // ---- 2. 执行严格逻辑匹配 ----
            MatchResult matchResult = executeStrictMatch(sixChannel, symptomIris, concomitantPathologies);

            // ---- 3. 构造输出变量 ----
            Map<String, Object> result = new LinkedHashMap<>();
            result.put("matchedFormulas", matchResult.getMatchedFormulaIris());
            result.put("bestMatchFormulaIri", matchResult.getBestMatchIri());
            result.put("bestMatchFormulaLabel", matchResult.getBestMatchLabel());
            result.put("clinicalCaseIri", clinicalCaseIri);

            // 附加信息：用于前端展示或第五步参考
            result.put("matchStatus", matchResult.getStatus().name());
            result.put("differentialHint", matchResult.getDifferentialHint());
            result.put("matchedPatternIris", matchResult.getMatchedPatternIris());

            // ---- 4. 完成任务 ----
            client.newCompleteCommand(job.getKey())
                    .variables(result)
                    .send().join();

            log.info("✅ step4-fangzheng-match 完成 | status={} | best={}",
                    matchResult.getStatus(), matchResult.getBestMatchIri());

        } catch (Exception e) {
            log.error("❌ step4-fangzheng-match 失败", e);
            client.newThrowErrorCommand(job.getKey())
                    .errorCode("STEP4_FANGZHENG_FAILED")
                    .errorMessage("方证匹配异常: " + e.getMessage())
                    .send().join();
        }
    }

    // ==================================================================
    // 核心匹配逻辑：严格集合运算，无权重
    // ==================================================================
    /**
     * 执行严格的方证对应匹配。
     * 
     * 流程：
     *   阶段A：六经空间约束 → 仅检索属于当前六经的病证
     *   阶段B：主症完备性校验 → 方证has_symptom ⊆ 患者symptomIris（缺一不可）
     *   阶段C：兼夹兼容性校验 → 患者兼夹与方证has_concomitant交叉验证
     *   阶段D：结果判定 → 唯一/多方/无方
     */
    private MatchResult executeStrictMatch(String sixChannel,
                                           List<String> symptomIris,
                                           List<String> concomitantPathologies) {

        OWLOntologyService ontService = backendService.getOntologyService();
        OWLDataFactory df = ontService.getDataFactory();
        OWLReasoner reasoner = backendService.getReasonerService().getReasoner();

        Set<String> patientSymptoms = new HashSet<>(symptomIris != null ? symptomIris : Collections.emptyList());
        Set<String> patientConcomitants = new HashSet<>(
                concomitantPathologies != null ? concomitantPathologies : Collections.emptyList());

        // ============================================================
        // 阶段A：六经空间约束
        // 从本体中获取所有 DiseasePattern，筛选 belongs_to_channel 包含当前六经者
        // ============================================================
        OWLClass diseasePatternClass = df.getOWLClass(IRI.create(TCM_NS + "DiseasePattern"));
        OWLObjectProperty belongsToChannel = df.getOWLObjectProperty(IRI.create(TCM_NS + "belongs_to_channel"));
        OWLObjectProperty hasSymptom = df.getOWLObjectProperty(IRI.create(TCM_NS + "has_symptom"));
        OWLObjectProperty hasOrSymptom = df.getOWLObjectProperty(IRI.create(BZ_NS + "has_or_symptom"));
        OWLObjectProperty hasConcomitant = df.getOWLObjectProperty(IRI.create(BZ_NS + "has_concomitant"));
        OWLObjectProperty hasPulse = df.getOWLObjectProperty(IRI.create(TCM_NS + "has_pulse"));

        Set<OWLNamedIndividual> allPatterns = reasoner.getInstances(diseasePatternClass, true)
                .entities().collect(Collectors.toSet());

        List<OWLNamedIndividual> channelFilteredPatterns = new ArrayList<>();

        for (OWLNamedIndividual pattern : allPatterns) {
            Set<String> patternChannels = getChannelIris(pattern, belongsToChannel, reasoner);
            if (patternChannels.contains(sixChannel)) {
                channelFilteredPatterns.add(pattern);
            }
        }

        log.debug("阶段A完成：六经[{}]下候选病证数={}", sixChannel, channelFilteredPatterns.size());

        // ============================================================
        // 阶段B：主症完备性校验（严格子集）
        // 规则：方证的 has_symptom 集合必须是患者症状的子集
        //       即：方证要求的每一个主症，患者都必须具备
        //       has_or_symptom 不参与此校验
        // ============================================================
        List<OWLNamedIndividual> symptomMatchedPatterns = new ArrayList<>();

        for (OWLNamedIndividual pattern : channelFilteredPatterns) {
            Set<String> requiredSymptoms = getSymptomIris(pattern, hasSymptom, reasoner);

            // 若方证无主症定义（如类别占位），跳过
            if (requiredSymptoms.isEmpty()) {
                log.debug("  跳过（无主症定义）: {}", pattern.getIRI().getShortForm());
                continue;
            }

            // 严格子集校验：方证要求的每个主症，患者必须全部具备
            if (patientSymptoms.containsAll(requiredSymptoms)) {
                symptomMatchedPatterns.add(pattern);
                log.debug("  ✓ 主症完备: {} (要求{}个主症全部命中)",
                        pattern.getIRI().getShortForm(), requiredSymptoms.size());
            } else {
                // 记录缺失症状（用于调试，不输出给BPMN）
                Set<String> missing = new HashSet<>(requiredSymptoms);
                missing.removeAll(patientSymptoms);
                log.trace("  ✗ 主症不全: {} | 缺失: {}",
                        pattern.getIRI().getShortForm(), missing);
            }
        }

        log.debug("阶段B完成：主症完备的病证数={}", symptomMatchedPatterns.size());

        // ============================================================
        // 阶段C：兼夹兼容性校验
        // 规则：
        //   (1) 方证有has_concomitant 且 患者有兼夹 → 必须交集非空
        //   (2) 方证有has_concomitant 且 患者无兼夹 → 排除（方证专为某兼夹设）
        //   (3) 方证无has_concomitant → 无论患者有无兼夹，均通过（纯六经方）
        // ============================================================
        List<OWLNamedIndividual> finalMatchedPatterns = new ArrayList<>();

        for (OWLNamedIndividual pattern : symptomMatchedPatterns) {
            Set<String> patternConcomitants = getConcomitantIris(pattern, hasConcomitant, reasoner);

            if (patternConcomitants.isEmpty()) {
                // 情况(3)：纯六经方，无兼夹指定，直接通过
                finalMatchedPatterns.add(pattern);
            } else if (!patientConcomitants.isEmpty()) {
                // 情况(1)：双方都有兼夹，检查交集
                Set<String> intersection = new HashSet<>(patternConcomitants);
                intersection.retainAll(patientConcomitants);
                if (!intersection.isEmpty()) {
                    finalMatchedPatterns.add(pattern);
                    log.debug("  ✓ 兼夹兼容: {} | 交集={}",
                            pattern.getIRI().getShortForm(), intersection);
                } else {
                    log.debug("  ✗ 兼夹不兼容: {} | 方证要求={} 患者实际={}",
                            pattern.getIRI().getShortForm(), patternConcomitants, patientConcomitants);
                }
            } else {
                // 情况(2)：方证指定兼夹但患者无此兼夹 → 排除
                log.debug("  ✗ 方证要求兼夹{}但患者无兼夹，排除: {}",
                        patternConcomitants, pattern.getIRI().getShortForm());
            }
        }

        log.debug("阶段C完成：最终匹配病证数={}", finalMatchedPatterns.size());

        // ============================================================
        // 阶段D：通过方剂反查，构造输出
        // 病证 → 方剂 的映射通过 tcm:indicated_for 反向查询
        // ============================================================
        return buildMatchResult(finalMatchedPatterns, df, reasoner, sixChannel);
    }

    // ==================================================================
    // 阶段D：构造匹配结果（病证→方剂映射）
    // ==================================================================
    private MatchResult buildMatchResult(List<OWLNamedIndividual> matchedPatterns,
                                         OWLDataFactory df,
                                         OWLReasoner reasoner,
                                         String sixChannel) {

        OWLObjectProperty indicatedFor = df.getOWLObjectProperty(IRI.create(TCM_NS + "indicated_for"));

        // 收集所有匹配到的方剂IRI（去重）
        LinkedHashSet<String> matchedFormulaIris = new LinkedHashSet<>();
        LinkedHashSet<String> matchedPatternIris = new LinkedHashSet<>();
        Map<String, String> formulaToPattern = new LinkedHashMap<>(); // 方剂→病证 映射

        for (OWLNamedIndividual pattern : matchedPatterns) {
            String patternIri = pattern.getIRI().toString();
            matchedPatternIris.add(patternIri);

            // 反向查询：哪些方剂的 indicated_for 指向此病证
            // 注意：OWL Reasoner 的 getObjectPropertyValues 是正向的
            // 反向查询需要遍历所有方剂或使用 SPARQL
            // 此处使用反向属性遍历
            Set<OWLNamedIndividual> formulas = findFormulasIndicatedFor(pattern, indicatedFor, reasoner, df);
            for (OWLNamedIndividual formula : formulas) {
                String formulaIri = formula.getIRI().toString();
                matchedFormulaIris.add(formulaIri);
                formulaToPattern.put(formulaIri, patternIri);
            }
        }

        // ---- 结果判定 ----
        MatchResult result = new MatchResult();
        result.setMatchedPatternIris(new ArrayList<>(matchedPatternIris));

        if (matchedFormulaIris.isEmpty()) {
            // 无匹配：当前六经+症状组合下无对应方证
            result.setStatus(MatchStatus.NO_MATCH);
            result.setBestMatchIri(null);
            result.setBestMatchLabel("无对应方证——请复核四诊信息或审视六经归属");
            result.setDifferentialHint(null);

        } else if (matchedFormulaIris.size() == 1) {
            // 唯一匹配：方证确定
            String theOne = matchedFormulaIris.iterator().next();
            result.setStatus(MatchStatus.UNIQUE_MATCH);
            result.setMatchedFormulaIris(new ArrayList<>(matchedFormulaIris));
            result.setBestMatchIri(theOne);
            result.setBestMatchLabel(resolveFormulaLabel(theOne));
            result.setDifferentialHint(null);

        } else {
            // 多方并存：需要鉴别诊断，不强行选择
            result.setStatus(MatchStatus.AMBIGUOUS);
            result.setMatchedFormulaIris(new ArrayList<>(matchedFormulaIris));
            result.setBestMatchIri(null); // 不指定"最佳"，交由医师判断
            result.setBestMatchLabel("多方证并存，需鉴别");
            result.setDifferentialHint(buildDifferentialHint(matchedPatterns, df, reasoner));
        }

        return result;
    }

    // ==================================================================
    // 辅助方法：本体查询
    // ==================================================================

    /** 获取病证所属六经的IRI集合 */
    private Set<String> getChannelIris(OWLNamedIndividual pattern,
                                       OWLObjectProperty belongsToChannel,
                                       OWLReasoner reasoner) {
        NodeSet<OWLNamedIndividual> channels = reasoner.getObjectPropertyValues(pattern, belongsToChannel);
        return channels.entities()
                .map(ind -> ind.getIRI().toString())
                .collect(Collectors.toSet());
    }

    /** 获取病证的必见主症（has_symptom）IRI集合 */
    private Set<String> getSymptomIris(OWLNamedIndividual pattern,
                                       OWLObjectProperty hasSymptom,
                                       OWLReasoner reasoner) {
        NodeSet<OWLNamedIndividual> symptoms = reasoner.getObjectPropertyValues(pattern, hasSymptom);
        return symptoms.entities()
                .map(ind -> ind.getIRI().toString())
                .collect(Collectors.toSet());
    }

    /** 获取病证的兼夹（has_concomitant）IRI集合 */
    private Set<String> getConcomitantIris(OWLNamedIndividual pattern,
                                           OWLObjectProperty hasConcomitant,
                                           OWLReasoner reasoner) {
        NodeSet<OWLNamedIndividual> concomitants = reasoner.getObjectPropertyValues(pattern, hasConcomitant);
        return concomitants.entities()
                .map(ind -> ind.getIRI().toString())
                .collect(Collectors.toSet());
    }

    /** 获取病证的或然症（has_or_symptom）IRI集合——仅用于展示，不参与匹配 */
    private Set<String> getOrSymptomIris(OWLNamedIndividual pattern,
                                         OWLObjectProperty hasOrSymptom,
                                         OWLReasoner reasoner) {
        NodeSet<OWLNamedIndividual> orSymptoms = reasoner.getObjectPropertyValues(pattern, hasOrSymptom);
        return orSymptoms.entities()
                .map(ind -> ind.getIRI().toString())
                .collect(Collectors.toSet());
    }

    /**
     * 反向查询：找到所有 indicated_for 指向给定病证的方剂。
     * 实现方式：遍历方剂类的所有实例，检查其 indicated_for 值。
     * （生产环境建议用 SPARQL 或预建倒排索引）
     */
    private Set<OWLNamedIndividual> findFormulasIndicatedFor(OWLNamedIndividual targetPattern,
                                                             OWLObjectProperty indicatedFor,
                                                             OWLReasoner reasoner,
                                                             OWLDataFactory df) {
        OWLClass formulaClass = df.getOWLClass(IRI.create(FJ_NS + "Formula"));
        Set<OWLNamedIndividual> allFormulas = reasoner.getInstances(formulaClass, true)
                .entities().collect(Collectors.toSet());

        Set<OWLNamedIndividual> result = new HashSet<>();
        for (OWLNamedIndividual formula : allFormulas) {
            NodeSet<OWLNamedIndividual> patterns = reasoner.getObjectPropertyValues(formula, indicatedFor);
            boolean matches = patterns.entities()
                    .anyMatch(p -> p.getIRI().equals(targetPattern.getIRI()));
            if (matches) {
                result.add(formula);
            }
        }
        return result;
    }

    /** 解析方剂标签（优先取rdfs:label，其次取skos:prefLabel） */
    private String resolveFormulaLabel(String formulaIri) {
        try {
            List<String> synonyms = SkosSynonymReader.getSynonymsByOwlIndividual(formulaIri);
            if (synonyms != null && !synonyms.isEmpty()) {
                return synonyms.get(0);
            }
        } catch (Exception e) {
            log.warn("解析方剂标签失败: {}", formulaIri, e);
        }
        // 回退：取IRI短名
        return IRI.create(formulaIri).getShortForm();
    }

    /** 构建鉴别诊断提示（多方证并存时） */
    private String buildDifferentialHint(List<OWLNamedIndividual> matchedPatterns,
                                         OWLDataFactory df,
                                         OWLReasoner reasoner) {
        OWLObjectProperty hasOrSymptom = df.getOWLObjectProperty(IRI.create(BZ_NS + "has_or_symptom"));
        OWLObjectProperty hasPulse = df.getOWLObjectProperty(IRI.create(TCM_NS + "has_pulse"));

        StringBuilder sb = new StringBuilder();
        sb.append("以下方证同时满足主症条件，需通过或然症/脉象/腹诊鉴别：\n");

        for (OWLNamedIndividual pattern : matchedPatterns) {
            String label = pattern.getIRI().getShortForm();
            Set<String> orSymptoms = getOrSymptomIris(pattern, hasOrSymptom, reasoner);
            NodeSet<OWLNamedIndividual> pulses = reasoner.getObjectPropertyValues(pattern, hasPulse);
            Set<String> pulseIris = pulses.entities()
                    .map(p -> p.getIRI().getShortForm())
                    .collect(Collectors.toSet());

            sb.append("【").append(label).append("】");
            if (!orSymptoms.isEmpty()) {
                sb.append(" 或然症: ").append(String.join(", ", orSymptoms));
            }
            if (!pulseIris.isEmpty()) {
                sb.append(" | 典型脉: ").append(String.join(", ", pulseIris));
            }
            sb.append("\n");
        }

        return sb.toString();
    }

    // ==================================================================
    // 结果模型
    // ==================================================================

    /** 匹配状态枚举 */
    public enum MatchStatus {
        UNIQUE_MATCH,   // 唯一匹配：方证确定
        AMBIGUOUS,      // 多方并存：需鉴别
        NO_MATCH        // 无匹配：四诊不全或六经归属有误
    }

    /** 匹配结果封装 */
    public static class MatchResult {
        private MatchStatus status;
        private List<String> matchedFormulaIris = new ArrayList<>();
        private List<String> matchedPatternIris = new ArrayList<>();
        private String bestMatchIri;
        private String bestMatchLabel;
        private String differentialHint;

        // Getters & Setters
        public MatchStatus getStatus() { return status; }
        public void setStatus(MatchStatus status) { this.status = status; }

        public List<String> getMatchedFormulaIris() { return matchedFormulaIris; }
        public void setMatchedFormulaIris(List<String> iris) { this.matchedFormulaIris = iris; }

        public List<String> getMatchedPatternIris() { return matchedPatternIris; }
        public void setMatchedPatternIris(List<String> iris) { this.matchedPatternIris = iris; }

        public String getBestMatchIri() { return bestMatchIri; }
        public void setBestMatchIri(String iri) { this.bestMatchIri = iri; }

        public String getBestMatchLabel() { return bestMatchLabel; }
        public void setBestMatchLabel(String label) { this.bestMatchLabel = label; }

        public String getDifferentialHint() { return differentialHint; }
        public void setDifferentialHint(String hint) { this.differentialHint = hint; }
    }
}
```

## 四、与BPMN ioMapping的对应关系

| BPMN input 变量 | 代码中读取方式 | 用途 |
|---|---|---|
| `sixChannel` | `vars.get("sixChannel")` | 阶段A六经过滤 |
| `symptomIris` | `vars.get("symptomIris")` | 阶段B主症子集校验 |
| `concomitantPathologies` | `vars.get("concomitantPathologies")` | 阶段C兼夹兼容性 |
| `clinicalCaseIri` | `vars.get("clinicalCaseIri")` | 透传，不参与匹配逻辑 |

| BPMN output 变量 | 代码中写入 | 含义 |
|---|---|---|
| `matchedFormulas` | `List<String>` 方剂IRI列表 | 所有通过校验的方剂 |
| `bestMatchFormulaIri` | `String` 或 `null` | 唯一匹配时为该方；多方/无方时为null |
| `bestMatchFormulaLabel` | `String` | 人可读的方剂名称 |

## 五、关键设计决策说明

| 决策点 | 处理方式 | 理由 |
|---|---|---|
| `has_or_symptom` | **不参与**必要性校验 | 或然症"或见或不见"，非必见 |
| `has_pulse` | **不参与**排除逻辑 | 脉象为辅助佐证，原文多条未言脉 |
| `has_typical_tongue` | **不参与**排除逻辑 | 伤寒金匮原文不论舌，均为后世推定 |
| 多方证并存 | 输出全部 + `differentialHint` | 不强行选择，尊重临床决策权 |
| 无匹配 | 返回 `NO_MATCH` + 提示语 | 提示四诊不全或六经归属有误 |
| 合病（多经） | 阶段A检查 `channels ∋ sixChannel` | 合病方的 `belongs_to_channel` 含多经，任一命中即入候选 |

## 六、与旧代码的对比（删除项）

| 旧代码 | 新代码 | 理由 |
|---|---|---|
| Jaccard 相似度 | **删除** | 经方无"相似度"，只有"是"或"不是" |
| `concomitantBonus = 0.1 * size` | **删除** | 兼夹是过滤条件，不是加分项 |
| `FormulaScore` 排序类 | **删除** | 无评分即无排序 |
| `scores.sort(...)` 取前3 | **删除** | 不存在"前3"，只有"是/否/待定" |
| `limit(3)` | **删除** | 匹配到几个就是几个 |

---

此实现严格遵循胡老"有是证用是方"的原则，将方证对应还原为**逻辑判定**而非**概率推断**。系统不做"最像"的判断，只做"是不是"的判定。不是，就不是。
